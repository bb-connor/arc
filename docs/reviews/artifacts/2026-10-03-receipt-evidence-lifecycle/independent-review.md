Locations: `receipt_store/retained_read.rs:44`, `receipt_query/read.rs:108`,
`evidence_export.rs:234` in `chio-store-sqlite`.

Queries, point reads, and child exports subsequently read separate `chio_tool_receipts` /
`chio_child_receipts` projections. Their joins constrain sequence membership but do not

A concrete failure requires no forged signature: delete one archived tool source row while
preserving its claim-log row. Archive authentication still passes; ordinary queries and export

Correction: Within the pinned snapshot, validate exact committed-prefix source/log membership,
payload equality, and filter projections before querying or counting; alternatively derive
returned records and filtering from authenticated claim-log content. Include child records and
point lookups. Keep uncommitted archive suffixes excluded.

timestamp, capability and cost projections; substitute valid signed source payloads. Query,
count, point-read and export paths must reject divergence. Existing whole-table deletion tests
only exercise SQL failure and miss this defect.
