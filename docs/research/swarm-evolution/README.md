# Swarm evolution with preserved commitments

S1 extends a running swarm through the existing Chio authority and native
admission path. New work can be added within the original declared pool while
old allocations, continuation identities, treaty conditions and physical claims
remain intact.

The qualification runner reuses the existing D1 evidence machinery. It binds
the current repository inputs to full swarm/runtime crate tests, all-target
Clippy, formatting and the earlier delegation/native trajectories. Historical
funded evidence retains its own source pin.

The broader research objective is independently owned systems composing into
useful evolving programs. S1 implements the additive lifecycle seam in that
objective. It is not a finding that only Chio can enforce these rules or that
declared swarm units are financial backing.
