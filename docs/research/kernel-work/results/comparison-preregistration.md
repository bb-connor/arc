# Two-family comparison preregistration

2026-10-02. Registered before the new family adapter and its measurements.
G1 thresholds remain unchanged. No independent participants are available.

## Local experiment

Use PR #1172's support-to-public-issue and confined-research/bounded-return
families with the same unchanged KW1 core and equally provisioned B1. Use a
separate lab to preserve Task 4's exact source/result record. This is a synthetic
deterministic compatibility corpus, with no LLM or claim of task-quality gains.

Support materializes a title and issue body before approval. Confined research
materializes one enumerated decision and one evidence index, with no arbitrary
text, extra fields or oversized return. Its seed crossing, confined result and
parent decision are distinct from an issue publication. A declared qualified
host and genuine scoped approvals are inputs, not properties proved by this lab.
The adapter must bind family, exact payload, source version, recipient and owner
set before reducing a prepared action to KW1 symbols. Both arms receive the
same adapter. Count all adapter correctness logic as added work for both arms.

Run authorized cases, omitted owners, wrong authority class, altered bytes,
source version, family or recipient, unqualified confinement, oversized/unknown
return fields, lost ACK, unauthorized secondary channels and revoked result
audience. Keep positive companions and compare both arms' decisions and visible
states. Neither arm may consult injected effect truth. Denials, retained
uncertainty and physical effects are separate results. Shared reducer and shared
adapter bugs remain a limitation; direct expected-outcome assertions are needed.

No local run time, line count or number of checks estimates integration effort.
No policy exception or host repair is permitted to be omitted from the results.
Failed first runs are retained. Changes after preregistration are recorded.

## Six paired independent integration exercises

| Exercise | Family and integration change | Required oracle / failure |
| --- | --- | --- |
| I1 | Support: onboard a new issue endpoint/account | Exact approved bytes and recipient; one applied/lost-ACK event |
| I2 | Support: replace E1 endpoint with E2 endpoint | Unknown retained, no blind retry; independent sibling completes |
| I3 | Support: add an owner and change ACL | Old approval rejected; fresh complete approval succeeds |
| I4 | Research: onboard a fresh confined provider | Admitted seeds only; bounded decision useful to parent |
| I5 | Research: port bounded return schema | Extra fields, error/log/payment canaries blocked; approved return succeeds |
| I6 | Research: recover provider restart and parent cancellation | Original effect identity and charges retained; current audience enforced |

Counterbalance Chio/B1 order in three pairs each. Pin common task inputs,
provider semantics, budgets, approval policy, models/versions/prompts/sampling,
hardware and trust before each pair. Give B1 the same recovery primitives,
reusable libraries, training and assistance. Record all repairs to either arm.
Use independently administered keys, hosting, stores and policies, independently
written provider integrations and an independent verifier as required by
[the trial](../../../market/open-agent-work/06-independent-trial.md). The same
author running processes does not satisfy this boundary.

For each arm/pair retain initial platform hours, repeated hands-on setup hours,
training, assistance, debugging, adapter changes, manual approvals, human wait,
blocked wall time, model tokens/cost, kernel CPU/latency/state bytes, endpoint
effects, quality adjudication, failures, recoverable incidents, interventions,
database edits and bespoke repair. Event timestamps and source/provider pins
accompany raw records; independent operators attest the record. Preserve failed
and abandoned attempts. Count initial platform effort separately and estimate
break-even only from measured repeated costs.

Primary endpoint: median paired repeated hands-on time ratio <= 0.50, matched
safety/progress/quality, and >= 95% of scheduled recoverable incidents completed
without database edits or bespoke repair. Report all six ratios and uncertainty;
six pairs are exploratory, not a population estimate. Do not substitute a
ratio of aggregate means. Zero denominator or incomplete pairs are unresolved,
never a zero-cost win. Do not exclude failures to improve a median.

Keep Q1-Q10, H1-H5, C0-C3, compatibility stage, 30-task pilot, held-out power
calibration, H2 checker-cost thresholds and success noninferiority from the
existing trial unchanged. Retain buyer/seller/funder/resource views, failed
attempts, subsidies and capital-time accounting. This extension supplies
integration exercises; it does not replace the preregistered economic trial.

G3 reports four separate decisions: bounded mechanism reuse, independent
operation, integration advantage, useful economics. Only the first can be
decided by the local experiment. The other three remain unmeasured here.
