## Costs and limits

Maximum serialized controller state in these schedules is 1,366 JSON bytes;
maximum candidate top-level checks per explored command is nine. These are
properties of this small symbolic representation, not native memory, CPU work,
latency or economic cost. Both arms share state representation. The per-fixture
counts are retained, but differing guard grouping/short-circuiting makes them
unsuitable as a speed comparison. Immutable history grows with events.

The executable frontier implements existing known-precondition/owner-coverage
rules with a fixed graph and disjoint partitions. The witness explains why the
joins matter, but the program does not contain or prove an arbitrary-trace
cross-owner theorem. No Lean proof is supplied because G1 selected an empirical
reuse hypothesis, not a new theorem. Native Rust-hook correspondence is unproved.

The aggregate model state represents owner-local and selected settlement ports;
it is not evidence from independently administered participants. Cryptography,
canonical byte custody, durable stores, actual crashes, receiving-host isolation,
semantic classification, source authenticity, settlement non-equivocation and
provider closure are supplied axioms. Channel/owner binding probes are not a
universal information-flow proof. The shared transition adapter is a deliberate
common-mode limitation; independently specified assertions caught three defects
that parity alone would miss. B2/B3 were repaired on paper, not executed here.
