# Next decisive research boundary

The local D1/S1/treaty/F1 composition now has a runnable implementation and a
receiver contract. Additional local success counts cannot establish the
remaining claim of lower integration cost or useful agentic commerce.

1. Freeze the public contract and preregister the outside receiver exercise in
   `RECEIVER-TRIAL.md`. A separately operated implementation must negotiate its
   own policy, keys, capability and custody, then execute and recover using the
   same public record definitions. Record every interface clarification and
   pair-specific change. No outside operator is available yet.
2. Run the matched conventional construction with equal authority, signatures,
   backing, checker, durable storage and failure schedule. Compare actual
   integration changes, implementation time and recovery interventions. Allow
   competent ordinary capability and transaction libraries.
3. Replace the easy-to-check W0 demonstration with preregistered held-out useful
   work. Count wrong/missing results, checker and compute cost, failed attempts,
   capital duration and unresolved obligations. A gain must survive this full
   accounting and independent critique before the paper claims an advantage.

Final bilateral receipt delivery is a distinct product boundary. The current
collector proves local completion and original payment, while retaining the
missing remote co-signer diagnostic. A future transport/recovery design should
reuse existing receipt custody and federation machinery, and must not grant a
new parent veto over an already earned child payment. That work is not evidence
of independent operation or an economic result by itself.
