# Genesis schema stubs (Proposed, unregistered)

Spec-shaped drafts for the Genesis Coverage Program artifact family, kept in
the research tree DELIBERATELY: nothing here is registered, so the canonical
`spec/schemas/` manifest and `registry.json` stay untouched by a research
proposal (and clear of the pre-#974 registry freeze, PLAN.md section 0).
Registration happens at each schema's owning milestone
([GENESIS-PLAN.md](../GENESIS-PLAN.md): procurement-list at G1b, royalty-right
at G2, reliability-epoch at G3, operator-seat at G4), via the standard
four-place registration (ARCHITECTURE 7.1).

Contents:

- `royalty-right.schema.json` - the make-or-break Q2 artifact (ADR-0018 D2):
  a signed, non-transferable, forward-flowing claim on a fraction of the D7
  clearing fee. Inline signature per the chio-finding convention (no
  `SignedExportEnvelope` wrapper; ADR-0018 D1).
- `negative-fixtures/royalty-right.v999.json` - the `.v999` unsupported-schema
  negative fixture. It differs from a valid artifact ONLY in its `schema` id,
  so a fail-closed validator's unknown-schema rejection is isolated (no other
  field is malformed; explanatory prose lives here rather than in a
  `_comment` member, which `additionalProperties: false` would itself reject
  and thereby double up the rejection reasons).

The signature and id values in fixtures are placeholder zeros; real goldens
are generated by the G1a crate's fixture generator, mirroring the M0/M1
finding-family pattern.
