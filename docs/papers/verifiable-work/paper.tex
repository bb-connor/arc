\begin{abstract}
An autonomous agent may commit resources to a task before it knows the rest of
its plan. Executing such a plan across organizations requires each resource
owner to distinguish new work from changes to work already authorized. We
present Chio, a protocol and runtime kernel that makes this distinction
explicit. A work commitment links a selected tool call to its delegated
allowance, the receiver's authorization and a separately funded payment
agreement. The receiver verifies these links and durably assigns the execution
right to the original call. A plan grows by adding tasks while retaining
earlier allocations and execution rights; signing a new plan cannot renew a
consumed right. The escrow records acceptance against each task's own reserve,
so an earned child payment survives parent failure. Under the stated trust
assumptions, we establish preservation of resource bounds, invocation
identity and earned claims through plan growth and recovery. A Rust
implementation demonstrates the construction in a local execution that adds a
specialist after an initial survey returns, survives intermediary process loss
and collects the specialist's original claim.
\end{abstract}
