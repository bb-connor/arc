\begin{abstract}
An agent buying work from another organization needs more than a message channel
and permission to pay. The provider needs a funded obligation; the buyer needs
an agreed way to check the result; each organization needs to retain authority
over its own resources. We describe a work contract joining these three
conditions without a shared application operator. Each receiver authorizes
execution locally. Signed evidence binds the agreed input, acceptance procedure,
execution record and funding allocation. A separately funded subcontract can
become payable even when its parent fails. We give a conditional composition
argument, a reference implementation and a reproducible finite-state and
contract-bytecode evaluation. An ordinary transactional escrow matches the
monetary behavior on the same trace corpus: the contribution is the explicit
composition and its implementation, not a new escrow primitive. The implemented
profile trusts a selected verifier and settlement domain. It establishes a
bounded basis for exchanging checked work; independent operation, lower
integration cost and useful autonomous trade remain empirical questions.
\end{abstract}
