\section{Conclusion}
An agentic program must be able to outlive the process and organization
that started it. Chio gives it a stable unit: a work commitment bound
to delegated capacity, local admission, original execution and agreed
settlement.

Planners discover new tasks and collaborators. Treaties retain each owner's
admission conditions. Durable custody attaches recovery to admitted execution.
Funded claims preserve earned obligations after parent failure. The
implementation composes these rules in one evolving execution.

Chio makes local authority and lasting commitments compatible with programs
whose plans are still being written. Owners determine what may enter their
domains. Agents compose the work within those bounds.
