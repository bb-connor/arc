# Chio: A Peer-to-Peer Economy of Verifiable Work

Title approved by the repository owner and locked on 2026-09-14.

## Thesis

Independent agents can build working relationships without sharing an
application operator or surrendering local authority. A common work contract
connects bounded procurement, independently checkable results and funded
obligations across companies and borders.
