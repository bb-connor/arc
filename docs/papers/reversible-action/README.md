# Programmable Sovereignty Over Reversible Action

LaTeX project for `Programmable Sovereignty Over Reversible Action`. The paper extends the type-level amendment-admission discipline to the enforcement-response side of the polity lifecycle: a reversible executive action is a type whose constructor requires a positive time-to-live witness and an action class tag, while a destructive action reduces admission to bilateral predicate intersection between a device polity and an operator polity. The load-bearing composition theorem, mechanized in the paper-local `theorems.lean`, states that a chain of TTL-bounded amendments keeps the active constitution backward-refining the baseline on an explicit finite admission domain at every instant, preventing the predicate-ratchet failure mode. Build with `pdflatex paper.tex && pdflatex paper.tex` from this directory (the bibliography is inline; there is no BibTeX database). Text is intended for CC-BY-4.0 review circulation.

`theorems.lean` beside this README is a paper-local planning artifact: it is not built by `lake build`, is not listed in `formal/proof-manifest.toml`, and its declarations are not in `formal/theorem-inventory.json`. It is checked by hand with `cd formal/lean4/Chio && lake env lean ../../../docs/papers/reversible-action/theorems.lean` against the syntactic treaty model and elaborates with no `sorry`. Its `closure_to_syntactic_admission_bridge` and `destructive_action_requires_bilateral_admission` are instances of the proof-root theorems `bridge_pointwise` and `treaty_admission_iff_predicate_intersection`. The paper may describe these theorems as a paper-local mechanization and must not present them as proof-root results.
