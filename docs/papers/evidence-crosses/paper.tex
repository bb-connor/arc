\begin{abstract}
\noindent
An agent that calls a tool through an ordinary client holds whatever authority
its host process holds and leaves whatever record that process chooses to keep,
and when the call crosses into a second organization the receiver has nothing to
check but the sender's word. We describe a protocol built on one rule: authority
is minted and verified only inside the kernel that dispatches, against roots
that kernel activated itself, and nothing in a request can add a root; only
signed, content-addressed evidence crosses an organization boundary. The object
that crosses is the receipt. Locally it is a kernel-signed record of one
admission decision whose identity is the hash of its own content, written
durably before the caller sees a result and, when the exercised grant carries a
monetary cap, carrying what the call cost and who paid. Across a boundary it is
co-signed: a statement whose single subject is the digest of a receipt the
receiving kernel already holds, signed by exactly two keys the receiver pinned
before the request arrived, binding the agreement, the request hash, and a
single-use continuation. The statement is a pointer, not a bearer credential, so
every deviation is a hash mismatch, a signature failure, or a lookup that
returns nothing.
\end{abstract}
