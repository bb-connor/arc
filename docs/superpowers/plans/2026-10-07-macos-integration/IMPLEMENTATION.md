# macOS Native Host Integration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver native macOS services and Darwin ports for Chio applications and agent harnesses, independently of Chio frontends, with separately qualified user-session and service-host deployment profiles.

**Architecture:** Existing native kernel/process/resource/credential/storage owners expose supported bindings to applications, agent harnesses and Herdr. Darwin ports and launchd service packaging preserve those owners and their declared TCB. The C-layer operator controller and workbench/menu clients are optional consumers outside the TCB. Thin Seatbelt or evaluated VM adapters deny ambient access while Chio's native owners grant authority.

**Tech Stack:** Existing Rust kernel/process/security crates and bindings, Darwin IPC/launchd/credential ports, minimal ServiceManagement packaging bridge where required, and the exact selected isolation runtime. The required integration lanes are Claude Code, Codex, Pi, Hermes and the distinct Herdr workspace/plugin consumer. Actual host launchers/model relays use reconciled native owners; workbench and Swift/AppKit or SwiftUI remain optional clients. Python mini-swe is optional reference/conformance code only, never a default runner or delivery prerequisite.

**Spec:** [macOS annex](../../specs/2026-10-07-macos-integration/ANNEX.md), [shared desktop program](../../specs/2026-10-07-desktop-integration/README.md), [ADR-0038](../../../adr/ADR-0038-desktop-operator-program.md), [operator projection](../../specs/2026-10-07-desktop-integration/OPERATOR.md), [program map](../../../architecture/PROGRAM-MAP.md), and [qualification](../../specs/2026-10-07-desktop-integration/QUALIFICATION.md).

**Shared native contracts:** [HOST-CONTRACT](../../specs/2026-10-07-desktop-integration/HOST-CONTRACT.md), [CONSUMERS](../../specs/2026-10-07-desktop-integration/CONSUMERS.md), [CAPABILITIES](../../specs/2026-10-07-desktop-integration/CAPABILITIES.md), [FIRST-CLASS-INTEGRATIONS](../../specs/2026-10-07-desktop-integration/FIRST-CLASS-INTEGRATIONS.md), the proposed [RELEASE owner extension](../../specs/2026-10-07-desktop-integration/RELEASE.md), and [native service research](../../specs/2026-10-07-macos-integration/research/native-host-services.md).

## Global constraints

- `runtime_evidence: unavailable` applies to every work packet in this plan. No implementation/test step below has been run by writing it.
- Isolation denies; Chio grants. Any selected controller is outside the TCB and a separate process from gateway and host.
- Native service/API delivery first, consumed by an external harness and an independent application with all Chio frontends absent. Application/Herdr UX and orchestration strategy remain consumer responsibilities.
- User-session host and service host are distinct, independently qualified deployment profiles. A GUI-free user service cannot claim login independence; machine service scope cannot weaken human-session lock/credential/approval rules.
- Workbench, operator controller, menu bar, Finder Services, notifications and browser clients are optional add-ons. All their existing security/privacy tests remain mandatory when delivered; their absence cannot block independent native capabilities.
- Sealed single-owner unpaid W1 coding work, evaluator and selected artifact delivery are an optional resource profile. No sealed-first production ordering or mandatory workbench dependency remains.
- Claude Code, Codex, Pi and Hermes are four required first-class harnesses, each targeting at least one scoped protected profile and independent native installed Mac qualification under H01-H08. Herdr is a separate required first-class workspace/plugin consumer whose absence cannot stop native hosting. No Pi-first or mini-swe-first ordering remains; mini-swe is optional reference/conformance only. Cursor and OpenClaw retain the broader doc 19 six-host obligations without being counted in these four or silently deleted.
- Hook-mode sessions are `detect_only`. Native-shell workspace effects are `cannot_see`; only gateway-routed or adapter-routed MCP calls authorized before dispatch can be `prevent`.
- No new recovery, work/task, credential, approval, event or stop contract. Missing owner APIs block dependent implementation.
- Approval requires S28 roster, production approval-path integration/qualification of the existing passkey verifier, qualified installed approval intake and exact intent binding; any route using the Pi approval utility additionally requires its installed repair. Per-task stop is S4 closure; S8 phase 1 is the durable Kernel stop scope, not the later Tenant/Recovery phases.
- `native-descendant-v1` is retired. Seatbelt cannot substitute for its former ES/NE and independently qualified network-containment gates.
- ES/NE managed endpoint is a separate deferred track.
- The initial native-service build experiment uses Apple silicon arm64 and `MACOSX_DEPLOYMENT_TARGET=15.0`; backend minima and supported release tuples are separate.
- No runtime implementation starts from this documentation-only consolidation. Execution begins with the authorized dependency packet and its source reconciliation.
- No em dashes; preserve unrelated working-tree changes; public copy links only public Chio source and revisions verified there.

## Review focus

- A stale/forged same-user IPC peer after service restart must not inherit the previous peer's custody (M1).
- A lock or fast-user-switch event lost during review must not disclose a task or preserve a stale actionable review (M2/M3/M8).
- A native shell can use inherited descriptors, descendants or delegated services to bypass a simple executable/path policy (M4/M5/M7).
- A lost reply during artifact export or an interrupted upgrade can duplicate an effect or revive stale authority (M6/M8/M9).
- A path with Unicode/case collisions, symlink swaps or oversized archive expansion must not escape intake/export scope (M6/M8).
