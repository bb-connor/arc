# M1 Cooperate-0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Two independently operated hosts can cooperate across an organization boundary using Chio's shipped passport, challenge, federated-issue and evidence loop. The hosts are an Omarchy box (Org A) and a Mac (Org B). Keys live in OS custody, issuance waits for a reviewed operator approval, and the run produces an independent-operation record.

**Architecture:**
- **Key custody.** A new `chio-key-custody` crate resolves key references (`keychain:`, `secret-service:`, `credential:`) inside the two central seed loaders. All 40 existing call sites gain OS custody with no CLI signature change.
- **Issuance inbox.** trust-control gains an inbox: holders submit challenge-bound presentations, and operators list, approve or deny them. Approval reuses the existing federated-issue logic, extracted into one function.
- **Delivery.** User-session service templates, a review notifier and a dashboard panel provide the desktop moments. A two-domain end-to-end test makes the loop continuous in CI. A runbook and record template produce the real two-machine evidence.

**Tech Stack:**
- Rust 2021: axum, rusqlite, reqwest (blocking), security-framework 3.x (already in `Cargo.lock`), zeroize.
- Python 3 (runbook helpers).
- React and TypeScript with vitest (dashboard).
- systemd user units and launchd LaunchAgents.

**Spec:** `docs/superpowers/specs/2026-10-07-desktop-integration/NORTH-STAR-FLOWS.md` (approved 2026-10-08), sections 2, 3, 6 and 8 (M1).

**Spec corrections recorded by this plan** (Plan A Task 2 updates the spec):
1. Step 5 uses `chio api protect`, not `mcp serve-http`, because only API protect accepts presented capabilities.
2. Custody resolves at the seed-loading layer rather than through `SigningBackend`. Signing call sites take `Keypair` today. The at-rest protection is the same, and a `SigningBackend`-only path is needed only for non-exportable keys (out of M1 scope).
3. The portable kernel-core verifier status check is deferred. The portable envelope has no passport ID, and M1 uses the trust-control path, which already enforces `require_active_lifecycle`.

## Review Focus

These are the conditions most likely to bite an operator. Each gets a test in the task that owns it.

1. **A key reference that names a missing item.** `load_or_create_authority_keypair("keychain:...")` must not silently generate and store a new organization key. Test in Task 2: missing `credential:` refs error; missing `keychain:` and `secret-service:` refs create only through an explicit `chio key init` (Task 2 adds it). Plain loaders on OS refs refuse to create.
2. **A second submission for the same challenge.** It must be refused (409), not overwrite the pending request. Test in Task 4.
3. **Approving after the challenge expired.** Approval must fail and mark the request denied with reason `expired`. Test in Task 5.
4. **A holder submitting a presentation that fails policy.** It must never appear in the operator inbox. Test in Task 5.
5. **A revoked passport.** It must be refused at approval, and the inbox shows the lifecycle reason. Test in Task 7 (two-domain e2e).

//! OS-native custody for Chio signing seeds.
//!
//! A key reference names where a 32-byte Ed25519 seed (hex) lives. File paths
//! keep today's behaviour. OS references keep the seed encrypted at rest by
//! the platform: macOS login keychain, libsecret Secret Service, or a systemd
//! credential. The seed is loaded into process memory to sign; this is an
//! OS-protected software key, not a hardware-bound key.

use std::path::{Path, PathBuf};

use zeroize::Zeroizing;

mod credential;
#[cfg(target_os = "macos")]
mod keychain;
mod secret_tool;

pub use secret_tool::{CommandOutput, CommandRunner, SystemRunner};

/// Environment variable that, when set to `required`, refuses file paths.
pub const CUSTODY_ENV: &str = "CHIO_KEY_CUSTODY";

#[derive(Debug, Clone, PartialEq, Eq)]
pub enum KeyRef {
    File(PathBuf),
    LoginKeychain { service: String, account: String },
    SecretService { name: String },
    SystemdCredential { name: String },
}

#[derive(Debug, thiserror::Error)]
pub enum CustodyError {
    #[error("invalid key reference {0:?}: {1}")]
    InvalidReference(String, &'static str),
    #[error("key custody policy requires OS custody; refusing plaintext file {0}")]
    FileRefused(PathBuf),
    #[error("key reference is a file path; read it through the file loader")]
    NotOsCustody,
    #[error("{0} is not available on this platform")]
    Unsupported(&'static str),
    #[error("{0}")]
    Backend(String),
    #[error("credential:{0} is read-only; provision it with `systemd-creds encrypt`")]
    ReadOnly(String),
}

fn valid_name(value: &str) -> bool {
    !value.is_empty()
        && value != "."
        && value != ".."
        && value.chars().all(|c| c.is_ascii_alphanumeric() || matches!(c, '-' | '_' | '.'))
}

impl KeyRef {
    pub fn parse(raw: &Path) -> Result<Self, CustodyError> {
        let text = raw.to_string_lossy();
        let bad = |why| CustodyError::InvalidReference(text.to_string(), why);
        if let Some(rest) = text.strip_prefix("keychain:") {
            let (service, account) = rest.split_once('/').ok_or_else(|| bad("expected keychain:<service>/<account>"))?;
            if service.is_empty() || account.is_empty() || account.contains('/') {
                return Err(bad("expected keychain:<service>/<account>"));
            }
            return Ok(Self::LoginKeychain { service: service.to_string(), account: account.to_string() });
        }
        if let Some(name) = text.strip_prefix("secret-service:") {
            if !valid_name(name) {
                return Err(bad("expected secret-service:<name> with [A-Za-z0-9._-]"));
            }
            return Ok(Self::SecretService { name: name.to_string() });
        }
        if let Some(name) = text.strip_prefix("credential:") {
            if !valid_name(name) {
                return Err(bad("expected credential:<name> with [A-Za-z0-9._-]"));
            }
            return Ok(Self::SystemdCredential { name: name.to_string() });
        }
        Ok(Self::File(raw.to_path_buf()))
    }

    #[must_use]
    pub fn is_os_custody(&self) -> bool {
        !matches!(self, Self::File(_))
    }

    #[must_use]
    pub fn describe(&self) -> String {
        match self {
            Self::File(path) => format!("plaintext file {} (development only)", path.display()),
            Self::LoginKeychain { service, account } => format!("macOS login keychain {service}/{account}"),
            Self::SecretService { name } => format!("Secret Service item chio-key={name}"),
            Self::SystemdCredential { name } => format!("systemd credential {name}"),
        }
    }
}

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum CustodyPolicy {
    AllowFiles,
    RequireOsCustody,
}

impl CustodyPolicy {
    #[must_use]
    pub fn from_env() -> Self {
        match std::env::var(CUSTODY_ENV) {
            Ok(value) if value.trim().eq_ignore_ascii_case("required") => Self::RequireOsCustody,
            _ => Self::AllowFiles,
        }
    }

    pub fn check(&self, key: &KeyRef) -> Result<(), CustodyError> {
        match (self, key) {
            (Self::RequireOsCustody, KeyRef::File(path)) => Err(CustodyError::FileRefused(path.clone())),
            _ => Ok(()),
        }
    }
}

/// Read a seed from OS custody. `Ok(None)` means the item does not exist.
pub fn read_seed_hex(key: &KeyRef) -> Result<Option<Zeroizing<String>>, CustodyError> {
    match key {
        KeyRef::File(_) => Err(CustodyError::NotOsCustody),
        KeyRef::SystemdCredential { name } => credential::read_from_env(name),
        KeyRef::SecretService { name } => secret_tool::lookup(&SystemRunner, name),
        #[cfg(target_os = "macos")]
        KeyRef::LoginKeychain { service, account } => keychain::read(service, account),
        #[cfg(not(target_os = "macos"))]
        KeyRef::LoginKeychain { .. } => Err(CustodyError::Unsupported("macOS keychain")),
    }
}

/// Store a seed in OS custody.
pub fn write_seed_hex(key: &KeyRef, seed_hex: &str) -> Result<(), CustodyError> {
    match key {
        KeyRef::File(_) => Err(CustodyError::NotOsCustody),
        KeyRef::SystemdCredential { name } => Err(CustodyError::ReadOnly(name.clone())),
        KeyRef::SecretService { name } => secret_tool::store(&SystemRunner, name, seed_hex),
        #[cfg(target_os = "macos")]
        KeyRef::LoginKeychain { service, account } => keychain::write(service, account, seed_hex),
        #[cfg(not(target_os = "macos"))]
        KeyRef::LoginKeychain { .. } => Err(CustodyError::Unsupported("macOS keychain")),
    }
}

        .ok_or_else(|| CustodyError::Backend("CREDENTIALS_DIRECTORY is not set; start the service with LoadCredentialEncrypted=".into()))?;

pub(crate) fn read_from_dir(dir: &Path, name: &str) -> Result<Option<Zeroizing<String>>, CustodyError> {

    }
}

use std::io::Write;
use std::process::{Command, Stdio};

use zeroize::Zeroizing;

use crate::CustodyError;

const ATTRIBUTE: &str = "chio-key";

pub struct CommandOutput {
    pub success: bool,
    pub stdout: Zeroizing<Vec<u8>>,
    pub stderr: Vec<u8>,
}

pub trait CommandRunner {
    fn run(&self, program: &str, args: &[&str], stdin: Option<&[u8]>) -> std::io::Result<CommandOutput>;
}

pub struct SystemRunner;

impl CommandRunner for SystemRunner {
    fn run(&self, program: &str, args: &[&str], stdin: Option<&[u8]>) -> std::io::Result<CommandOutput> {
        let mut child = Command::new(program)
            .args(args)
            .stdin(if stdin.is_some() { Stdio::piped() } else { Stdio::null() })
            .stdout(Stdio::piped())
            .stderr(Stdio::piped())
            .spawn()?;
        if let (Some(input), Some(mut pipe)) = (stdin, child.stdin.take()) {
            pipe.write_all(input)?;
        }
        let output = child.wait_with_output()?;
        Ok(CommandOutput { success: output.status.success(), stdout: Zeroizing::new(output.stdout), stderr: output.stderr })
    }
}

pub(crate) fn lookup(runner: &dyn CommandRunner, name: &str) -> Result<Option<Zeroizing<String>>, CustodyError> {
    let output = runner
        .run("secret-tool", &["lookup", ATTRIBUTE, name], None)
        .map_err(|error| CustodyError::Backend(format!("run secret-tool: {error} (install libsecret)")))?;
    if output.success {
        let text = String::from_utf8(output.stdout.to_vec())
            .map_err(|_| CustodyError::Backend("secret-tool returned non-UTF-8 output".into()))?;
        return Ok(Some(Zeroizing::new(text.trim().to_string())));
    }
    if output.stderr.is_empty() {
        return Ok(None);
    }
    Err(CustodyError::Backend(format!("secret-tool lookup failed: {}", String::from_utf8_lossy(&output.stderr).trim())))
}

pub(crate) fn store(runner: &dyn CommandRunner, name: &str, seed_hex: &str) -> Result<(), CustodyError> {
    let label = format!("Chio key {name}");
    let output = runner
        .run("secret-tool", &["store", "--label", &label, ATTRIBUTE, name], Some(seed_hex.as_bytes()))
        .map_err(|error| CustodyError::Backend(format!("run secret-tool: {error} (install libsecret)")))?;
    if output.success {
        Ok(())
    } else {
        Err(CustodyError::Backend(format!("secret-tool store failed: {}", String::from_utf8_lossy(&output.stderr).trim())))
    }
}

use security_framework::passwords::{get_generic_password, set_generic_password};
use zeroize::Zeroizing;

use crate::CustodyError;

const ERR_SEC_ITEM_NOT_FOUND: i32 = -25300;

pub(crate) fn read(service: &str, account: &str) -> Result<Option<Zeroizing<String>>, CustodyError> {
    match get_generic_password(service, account) {
        Ok(bytes) => {
            let bytes = Zeroizing::new(bytes);
            let text = std::str::from_utf8(&bytes)
                .map_err(|_| CustodyError::Backend("keychain item is not UTF-8".into()))?;
            Ok(Some(Zeroizing::new(text.trim().to_string())))
        }
        Err(error) if error.code() == ERR_SEC_ITEM_NOT_FOUND => Ok(None),
        Err(error) => Err(CustodyError::Backend(format!("keychain read {service}/{account}: {error}"))),
    }
}

pub(crate) fn write(service: &str, account: &str, seed_hex: &str) -> Result<(), CustodyError> {
    set_generic_password(service, account, seed_hex.as_bytes())
        .map_err(|error| CustodyError::Backend(format!("keychain write {service}/{account}: {error}")))
}

        .map(|r| r.describe())
        .map_err(|e| CliError::cli_other_error(e.to_string()))

fn print(keypair: &Keypair, key: &Path, created: bool, json_output: bool) -> Result<(), CliError> {
    let public_key = keypair.public_key();
    let did = chio_did::DidChio::from_public_key(public_key.clone()).to_string();
    let custody = describe(key)?;
    if json_output {
        println!(
            "{}",
            serde_json::json!({ "publicKey": public_key.to_hex(), "did": did, "custody": custody, "created": created })
        );
    } else {
        println!("public_key: {}", public_key.to_hex());
        println!("did:        {did}");
        println!("custody:    {custody}");
        println!("created:    {created}");
    }
    Ok(())
}

fn init(key: &Path, json_output: bool) -> Result<(), CliError> {
    if let Some(seed_hex) = chio_control_plane::read_key_seed_hex(key)? {
        let keypair = Keypair::from_seed_hex(seed_hex.as_str())?;
        return print(&keypair, key, false, json_output);
    }
    let keypair = Keypair::generate();
    let reference = chio_key_custody::KeyRef::parse(key).map_err(|e| CliError::cli_other_error(e.to_string()))?;
    if reference.is_os_custody() {
        chio_key_custody::write_seed_hex(&reference, &keypair.seed_hex())
            .map_err(|e| CliError::cli_other_error(e.to_string()))?;

        return print(&Keypair::from_seed_hex(seed_hex.as_str())?, key, true, json_output);
    }
    print(&keypair, key, true, json_output)
}

//! Pending federated-issuance requests awaiting an operator decision.

use std::fs;
use std::path::{Path, PathBuf};

use rusqlite::{params, Connection, OptionalExtension};
use serde::{Deserialize, Serialize};

use crate::CliError;

pub const MAX_PENDING_ISSUANCE_REQUESTS: usize = 256;
pub const DUPLICATE_SUBMISSION: &str = "issuance request already submitted for this challenge";

#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize)]
#[serde(rename_all = "kebab-case")]
pub enum IssuanceRequestStatus {
    Pending,
    Approved,
    Denied,
}

impl IssuanceRequestStatus {
    fn as_str(self) -> &'static str {
        match self {
            Self::Pending => "pending",
            Self::Approved => "approved",
            Self::Denied => "denied",
        }
    }

    fn parse(value: &str) -> Result<Self, CliError> {
        match value {
            "pending" => Ok(Self::Pending),
            "approved" => Ok(Self::Approved),
            "denied" => Ok(Self::Denied),
            other => Err(CliError::cli_other_error(format!("unknown issuance request status {other}"))),
        }
    }
}

#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize)]
#[serde(rename_all = "camelCase")]
pub struct IssuanceRequestRecord {
    pub challenge_id: String,
    pub subject: String,
    pub verifier: String,
    pub presentation_json: String,
    pub challenge_json: String,
    pub submitted_at: u64,
    pub expires_at: u64,
    pub status: IssuanceRequestStatus,
    pub decided_at: Option<u64>,
    pub capability_id: Option<String>,
    pub decision_reason: Option<String>,
}

#[derive(Debug, Clone)]
pub struct IssuanceRequestStore {
    path: PathBuf,
}

fn to_i64(value: u64) -> Result<i64, CliError> {
    i64::try_from(value).map_err(|_| CliError::cli_other_error("timestamp exceeds i64".to_string()))
}

impl IssuanceRequestStore {
    pub fn open(path: &Path) -> Result<Self, CliError> {
        let store = Self { path: path.to_path_buf() };
        store.connection()?.execute_batch(
            "CREATE TABLE IF NOT EXISTS federation_issuance_requests (
                challenge_id TEXT PRIMARY KEY,
                subject TEXT NOT NULL,
                verifier TEXT NOT NULL,
                presentation_json TEXT NOT NULL,
                challenge_json TEXT NOT NULL,
                submitted_at INTEGER NOT NULL,
                expires_at INTEGER NOT NULL,
                status TEXT NOT NULL,
                decided_at INTEGER,
                capability_id TEXT,
                decision_reason TEXT
            );
            CREATE INDEX IF NOT EXISTS idx_federation_issuance_requests_status
                ON federation_issuance_requests(status, submitted_at);",
        )?;
        Ok(store)
    }

    fn connection(&self) -> Result<Connection, CliError> {
        if let Some(parent) = self.path.parent() {
            fs::create_dir_all(parent)?;
        }
        Ok(Connection::open(&self.path)?)
    }

    pub fn submit(&self, record: &IssuanceRequestRecord) -> Result<(), CliError> {
        let connection = self.connection()?;
        let pending: i64 = connection.query_row(
            "SELECT COUNT(*) FROM federation_issuance_requests WHERE status = 'pending'",
            [],
            |row| row.get(0),
        )?;
        if usize::try_from(pending).unwrap_or(usize::MAX) >= MAX_PENDING_ISSUANCE_REQUESTS {
            return Err(CliError::cli_other_error("too many pending issuance requests".to_string()));
        }
        let inserted = connection.execute(
            "INSERT OR IGNORE INTO federation_issuance_requests (
                challenge_id, subject, verifier, presentation_json, challenge_json,
                submitted_at, expires_at, status, decided_at, capability_id, decision_reason
            ) VALUES (?1, ?2, ?3, ?4, ?5, ?6, ?7, 'pending', NULL, NULL, NULL)",
            params![
                record.challenge_id,
                record.subject,
                record.verifier,
                record.presentation_json,
                record.challenge_json,
                to_i64(record.submitted_at)?,
                to_i64(record.expires_at)?,
            ],
        )?;
        if inserted == 0 {
            return Err(CliError::cli_other_error(DUPLICATE_SUBMISSION.to_string()));
        }
        Ok(())
    }

    fn row(row: &rusqlite::Row<'_>) -> rusqlite::Result<(IssuanceRequestRecord, String)> {
        let as_u64 = |value: i64| u64::try_from(value).unwrap_or(0);
        Ok((
            IssuanceRequestRecord {
                challenge_id: row.get(0)?,
                subject: row.get(1)?,
                verifier: row.get(2)?,
                presentation_json: row.get(3)?,
                challenge_json: row.get(4)?,
                submitted_at: as_u64(row.get(5)?),
                expires_at: as_u64(row.get(6)?),
                status: IssuanceRequestStatus::Pending,
                decided_at: row.get::<_, Option<i64>>(8)?.map(as_u64),
                capability_id: row.get(9)?,
                decision_reason: row.get(10)?,
            },
            row.get::<_, String>(7)?,
        ))
    }

    const COLUMNS: &'static str = "challenge_id, subject, verifier, presentation_json, challenge_json, \
        submitted_at, expires_at, status, decided_at, capability_id, decision_reason";

    pub fn get(&self, challenge_id: &str) -> Result<Option<IssuanceRequestRecord>, CliError> {
        let connection = self.connection()?;
        let found = connection
            .query_row(
                &format!("SELECT {} FROM federation_issuance_requests WHERE challenge_id = ?1", Self::COLUMNS),
                params![challenge_id],
                Self::row,
            )
            .optional()?;
        found
            .map(|(mut record, status)| {
                record.status = IssuanceRequestStatus::parse(&status)?;
                Ok(record)
            })
            .transpose()
    }

    pub fn list(&self, status: Option<IssuanceRequestStatus>) -> Result<Vec<IssuanceRequestRecord>, CliError> {
        let connection = self.connection()?;
        let sql = format!(
            "SELECT {} FROM federation_issuance_requests WHERE (?1 IS NULL OR status = ?1) ORDER BY submitted_at",
            Self::COLUMNS
        );
        let mut statement = connection.prepare(&sql)?;
        let rows = statement.query_map(params![status.map(IssuanceRequestStatus::as_str)], Self::row)?;
        let mut out = Vec::new();
        for row in rows {
            let (mut record, status) = row?;
            record.status = IssuanceRequestStatus::parse(&status)?;
            out.push(record);
        }
        Ok(out)
    }

    pub fn decide(
        &self,
        challenge_id: &str,
        status: IssuanceRequestStatus,
        now: u64,
        capability_id: Option<&str>,
        reason: Option<&str>,
    ) -> Result<(), CliError> {
        let changed = self.connection()?.execute(
            "UPDATE federation_issuance_requests
             SET status = ?2, decided_at = ?3, capability_id = ?4, decision_reason = ?5
             WHERE challenge_id = ?1 AND status = 'pending'",
            params![challenge_id, status.as_str(), to_i64(now)?, capability_id, reason],
        )?;
        if changed == 0 {
            return Err(CliError::cli_other_error(format!(
                "issuance request {challenge_id} is not pending"
            )));
        }
        Ok(())
    }
}

//! Federated issuance inbox: holders submit challenge-bound presentations;
//! operators approve (runs federated issue) or deny.

use super::report_rendering::forward_post_to_leader;
use super::report_validation::validate_service_auth;
use super::*;
use crate::issuance_requests::{
    IssuanceRequestRecord, IssuanceRequestStatus, IssuanceRequestStore, DUPLICATE_SUBMISSION,
};

fn inbox_store(state: &TrustServiceState) -> Result<IssuanceRequestStore, Response> {
    let path = configured_verifier_challenge_db_path(&state.config)
        .map_err(|error| plain_http_error(StatusCode::CONFLICT, &error.to_string()))?;
    IssuanceRequestStore::open(path).map_err(|error| plain_http_error(StatusCode::CONFLICT, &error.to_string()))
}

pub(crate) async fn handle_public_submit_issuance_request(
    State(state): State<TrustServiceState>,
    Json(payload): Json<SubmitIssuanceRequest>,
) -> Response {
    match forward_post_to_leader(&state, PUBLIC_FEDERATION_ISSUANCE_REQUESTS_PATH, &payload).await {
        Ok(Some(response)) => return response,
        Ok(None) => {}
        Err(response) => return response,
    }
    let Some(challenge_id) = payload.presentation.challenge.challenge_id.clone().filter(|v| !v.trim().is_empty()) else {
        return plain_http_error(StatusCode::BAD_REQUEST, "issuance request requires a challenge_id");
    };
    let challenge_db = match configured_verifier_challenge_db_path(&state.config) {
        Ok(path) => path,
        Err(error) => return plain_http_error(StatusCode::CONFLICT, &error.to_string()),
    };
    let now = unix_timestamp_now();
    let stored = match PassportVerifierChallengeStore::open(challenge_db).and_then(|s| s.fetch_active(&challenge_id, now)) {
        Ok(challenge) => challenge,
        Err(error) => return plain_http_error(StatusCode::NOT_FOUND, &error.to_string()),
    };
    let request = VerifyPassportChallengeRequest {
        presentation: payload.presentation.clone(),
        expected_challenge: Some(stored.clone()),
    };
    let verification = match verify_passport_challenge_payload(&state, &request, Some(&stored), false) {
        Ok(verification) => verification,
        Err(response) => return response,
    };
    if !verification.accepted {
        return plain_http_error(StatusCode::FORBIDDEN, "passport presentation did not satisfy the verifier policy");
    }
    let expires_at = match crate::passport_verifier::unix_from_rfc3339(&stored.expires_at) {
        Ok(value) => value,
        Err(error) => return plain_http_error(StatusCode::BAD_REQUEST, &error.to_string()),
    };
    let record = IssuanceRequestRecord {
        challenge_id: challenge_id.clone(),
        subject: verification.subject.clone(),
        verifier: stored.verifier.clone(),
        presentation_json: match serde_json::to_string(&payload.presentation) {
            Ok(json) => json,
            Err(error) => return plain_http_error(StatusCode::BAD_REQUEST, &error.to_string()),
        },
        challenge_json: match serde_json::to_string(&stored) {
            Ok(json) => json,
            Err(error) => return plain_http_error(StatusCode::INTERNAL_SERVER_ERROR, &error.to_string()),
        },
        submitted_at: now,
        expires_at,
        status: IssuanceRequestStatus::Pending,
        decided_at: None,
        capability_id: None,
        decision_reason: None,
    };
    let store = match inbox_store(&state) {
        Ok(store) => store,
        Err(response) => return response,
    };
    match store.submit(&record) {
        Ok(()) => Json(SubmitIssuanceRequestResponse { challenge_id, status: IssuanceRequestStatus::Pending }).into_response(),
        Err(error) if error.to_string().contains(DUPLICATE_SUBMISSION) => plain_http_error(StatusCode::CONFLICT, DUPLICATE_SUBMISSION),
        Err(error) => plain_http_error(StatusCode::TOO_MANY_REQUESTS, &error.to_string()),
    }
}

#[derive(Debug, serde::Deserialize)]
pub(crate) struct IssuanceListQuery {
    status: Option<String>,
}

pub(crate) async fn handle_list_issuance_requests(
    State(state): State<TrustServiceState>,
    headers: HeaderMap,
    axum::extract::Query(query): axum::extract::Query<IssuanceListQuery>,
) -> Response {
    if let Err(response) = validate_service_auth(&headers, &state.config.service_token) {
        return response;
    }
    let status = match query.status.as_deref() {
        None => None,
        Some("pending") => Some(IssuanceRequestStatus::Pending),
        Some("approved") => Some(IssuanceRequestStatus::Approved),
        Some("denied") => Some(IssuanceRequestStatus::Denied),
        Some(other) => return plain_http_error(StatusCode::BAD_REQUEST, &format!("unknown status {other}")),
    };
    match inbox_store(&state).and_then(|store| {
        store.list(status).map_err(|error| plain_http_error(StatusCode::CONFLICT, &error.to_string()))
    }) {
        Ok(requests) => Json(IssuanceRequestList { requests }).into_response(),
        Err(response) => response,
    }
}

fn pending_or_error(store: &IssuanceRequestStore, challenge_id: &str) -> Result<IssuanceRequestRecord, Response> {
    match store.get(challenge_id) {
        Ok(Some(record)) if record.status == IssuanceRequestStatus::Pending => Ok(record),
        Ok(Some(_)) => Err(plain_http_error(StatusCode::CONFLICT, "issuance request is not pending")),
        Ok(None) => Err(plain_http_error(StatusCode::NOT_FOUND, "issuance request not found")),
        Err(error) => Err(plain_http_error(StatusCode::CONFLICT, &error.to_string())),
    }
}

pub(crate) async fn handle_approve_issuance_request(
    State(state): State<TrustServiceState>,
    headers: HeaderMap,
    axum::extract::Path(challenge_id): axum::extract::Path<String>,
    Json(payload): Json<ApproveIssuanceRequest>,
) -> Response {
    if let Err(response) = validate_service_auth(&headers, &state.config.service_token) {
        return response;
    }
    let store = match inbox_store(&state) {
        Ok(store) => store,
        Err(response) => return response,
    };
    let record = match pending_or_error(&store, &challenge_id) {
        Ok(record) => record,
        Err(response) => return response,
    };
    let now = unix_timestamp_now();
    if now >= record.expires_at {
        let _ = store.decide(&challenge_id, IssuanceRequestStatus::Denied, now, None, Some("expired"));
        return plain_http_error(StatusCode::GONE, "issuance request expired with its challenge");
    }
    let (presentation, expected_challenge) = match (
        serde_json::from_str(&record.presentation_json),
        serde_json::from_str(&record.challenge_json),
    ) {
        (Ok(presentation), Ok(challenge)) => (presentation, challenge),
        _ => return plain_http_error(StatusCode::INTERNAL_SERVER_ERROR, "stored issuance request is corrupt"),
    };
    let request = FederatedIssueRequest {
        presentation,
        expected_challenge,
        capability: payload.capability,
        admission_policy: payload.admission_policy,
        enterprise_identity: None,
        delegation_policy: payload.delegation_policy,
        upstream_capability_id: payload.upstream_capability_id,
    };
    match execute_federated_issue(&state, &request) {
        Ok(response) => {
            if let Err(error) = store.decide(&challenge_id, IssuanceRequestStatus::Approved, now, Some(&response.capability.id), None) {
                return plain_http_error(StatusCode::CONFLICT, &error.to_string());
            }
            Json(response).into_response()
        }
        Err(response) => {
            let reason = format!("federated issue refused with status {}", response.status());
            let _ = store.decide(&challenge_id, IssuanceRequestStatus::Denied, now, None, Some(&reason));
            response
        }
    }
}

pub(crate) async fn handle_deny_issuance_request(
    State(state): State<TrustServiceState>,
    headers: HeaderMap,
    axum::extract::Path(challenge_id): axum::extract::Path<String>,
    Json(payload): Json<DenyIssuanceRequest>,
) -> Response {
    if let Err(response) = validate_service_auth(&headers, &state.config.service_token) {
        return response;
    }
    let store = match inbox_store(&state) {
        Ok(store) => store,
        Err(response) => return response,
    };
    let record = match pending_or_error(&store, &challenge_id) {
        Ok(record) => record,
        Err(response) => return response,
    };
    let now = unix_timestamp_now();
    if let Ok(challenge) = serde_json::from_str::<PassportPresentationChallenge>(&record.challenge_json) {
        let _ = consume_challenge_if_configured(&state.config, &challenge, now);
    }
    if let Err(error) = store.decide(&challenge_id, IssuanceRequestStatus::Denied, now, None, Some(payload.reason.trim())) {
        return plain_http_error(StatusCode::CONFLICT, &error.to_string());
    }
    match store.get(&challenge_id) {
        Ok(Some(record)) => Json(record).into_response(),
        _ => plain_http_error(StatusCode::INTERNAL_SERVER_ERROR, "decided request vanished"),
    }
}

use std::collections::BTreeSet;
use std::process::Command;

use crate::CliError;

pub(crate) trait Notifier {
    fn notify(&self, title: &str, body: &str);
}

pub(crate) struct OsNotifier;

impl Notifier for OsNotifier {
    fn notify(&self, title: &str, body: &str) {
        if cfg!(target_os = "macos") {
            let script = format!("display notification {body:?} with title {title:?}");
            let _ = Command::new("osascript").args(["-e", &script]).status();
        } else {
            let _ = Command::new("notify-send").args(["--app-name=Chio", title, body]).status();
        }
    }
}

/// Returns the challenge IDs that were newly announced.
pub(crate) fn announce_new(seen: &mut BTreeSet<String>, pending: &[(String, String)], notifier: &dyn Notifier) -> Vec<String> {
    let mut announced = Vec::new();
    for (challenge_id, subject) in pending {
        if seen.insert(challenge_id.clone()) {
            notifier.notify("Chio: issuance review", &format!("Presentation from {subject} awaits review"));
            announced.push(challenge_id.clone());
        }
    }
    announced
}

pub(crate) fn watch(
    client: &chio_control_plane::trust_control::service_runtime::client::TrustControlClient,
    interval_seconds: u64,
) -> Result<(), CliError> {
    let mut seen = BTreeSet::new();
    loop {
        let list = client.list_issuance_requests(Some("pending"))?;
        let pending: Vec<(String, String)> = list.requests.into_iter().map(|r| (r.challenge_id, r.subject)).collect();
        announce_new(&mut seen, &pending, &OsNotifier);
        std::thread::sleep(std::time::Duration::from_secs(interval_seconds.max(5)));
    }
}

export interface IssuanceRequest {
  challengeId: string
  subject: string
  verifier: string
  status: 'pending' | 'approved' | 'denied'
  submittedAt: number
  expiresAt: number
  decisionReason?: string | null
}

export async function fetchIssuanceRequests(status = 'pending'): Promise<IssuanceRequest[]> {
  const res = await apiFetch(`/v1/federation/issuance-requests?status=${encodeURIComponent(status)}`)
  const body = (await res.json()) as { requests: IssuanceRequest[] }
  return body.requests
}

export async function denyIssuanceRequest(challengeId: string, reason: string): Promise<IssuanceRequest> {
  const res = await apiFetch(`/v1/federation/issuance-requests/${encodeURIComponent(challengeId)}/deny`, {
    method: 'POST',
    body: JSON.stringify({ reason }),
  })
  return (await res.json()) as IssuanceRequest
}
