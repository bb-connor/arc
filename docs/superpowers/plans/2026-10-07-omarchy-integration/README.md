# Linux native host and optional Omarchy delivery plan

`boundary_class: advisory_only` for this planning index; `planning_status: ready_after_adr`. No runtime readiness is implied.

Use the [shared native host plan](../2026-10-07-desktop-integration.md), [HOST-CONTRACT](../../specs/2026-10-07-desktop-integration/HOST-CONTRACT.md) and [platform implementation packets](IMPLEMENTATION.md). [ADR-0038](../../../adr/ADR-0038-desktop-operator-program.md) owns the accepted planning direction; actual native owner source and qualification gate implementation.

Deliver reusable Linux services/bindings, installed CLI/API/harness consumers and profile-specific lifecycle first. Qualify user-session and service-host enrollment separately. O2 adds an optional Omarchy consumer; it is not a dependency of native packages, coordination, resources, approval/stop or protected harness support. Sealed coding is one workload. Each host promotes against its own I01-I08/native evidence without waiting for a coding/frontend/all-six release.

[CONSUMERS](../../specs/2026-10-07-desktop-integration/CONSUMERS.md) carries installed native use, coordination, resource sharing and independent-organization acceptance. Preserve all applicable native failure cases; scope only presentation cases to selected add-ons. Candidate publication, installed qualification and supported release remain separate. The former P0-P7 platform program is retired.
