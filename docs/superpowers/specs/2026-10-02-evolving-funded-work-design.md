2. Each receiver installs its own signed treaty and runtime admission records.
3. The existing bilateral funded agreement binds the final immutable request.
4. The existing escrow deposits backing for that agreement's allocation.
5. The S1 owner installs checked additive growth by compare-and-swap. Earlier
   graph versions and continuation identities remain available unchanged.
6. Receiver admission checks all references; native custody acquires physical
   continuation resources and dispatches once. F1 retains original output,
   execution evidence, Finding and checked financial decision.
7. A child claim reaches the escrow's Payable state. Kill the intermediary

There is no distributed transaction between these owners. Failure before
dispatch can strand sealed capacity or funded escrow until its existing refund
rules apply. Recovery resumes original identities; it never silently assigns a
new request, allocation, continuation, beneficiary or financial decision.
