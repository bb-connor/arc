Coverage states:
- `Covered` - the threat ID has a populated test body at `crates/chio-conformance/tests/threats/<id>.rs`.
- `Partial` - fail-closed state; the threat-model coverage gate rejects partial coverage after M05.P4.
- `Pending` - no backing test yet; the threat-model-coverage CI gate accepts the entry because it is explicitly marked `pending` with a non-empty `deferred_to` in the JSON, but a green test must land before the owning milestone closes.
