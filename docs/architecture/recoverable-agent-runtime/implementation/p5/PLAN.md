# P5 execution plan

Phase: confined returns, architecture revision 3. The sealed P4 package is the
immutable baseline. ISO-01 through ISO-10 remain mandatory.

| Task | Deliverable | Obligations |
|---|---|---|
| P5-01 | Closed boundary, return contract, exact disclosure and independent integrity evidence | ISO-02, ISO-04, ISO-07 |
| P5-02 | Protected host reservations, ancestry, seed joins and permanent aggregate accounting | ISO-01, ISO-02, ISO-09, ISO-10 |
| P5-03 | Affine measured cage launch and separate observation context | ISO-03, ISO-08 |
| P5-04 | Immutable bounded return staging and fresh native parent admission before bytes | ISO-04, ISO-05, ISO-07 |
| P5-05 | Classified channel capture, cancellation and restart reconciliation | ISO-06, ISO-08 |
| P5-06 | Source review, portable/native tests and real Linux acceptance | All ten |

Initial profile: Linux x86_64 cage with retained measured executable/helper,
Landlock and independent seccomp, exact observed credentials, the host-fixed
environment `LANG=C`, `LC_ALL=C`, `TZ=UTC`, and one fixed argument. No inherited
environment, filesystem grants, network, broker, tools or model/provider context.
The child reads one host-mediated immutable artifact and returns one canonical
JSON boolean. A registered exact boolean projection, explicit disclosure
authority and separately scoped integrity evidence govern a useful parent
decision. All other stdout, stderr, errors, logs, files, callbacks, progress and
streams are withheld; no raw fallback or implicit completion projection exists.
Disabled provider/tool channels have zero call budgets. Expansion requires a
separately reviewed and enforced profile.

Bounds fixed before implementation: 16 children per parent scope, one measured
launch per logical child, eight seed versions, one observation version, 64 KiB
total immutable child input, eight bytes of canonical return, 16 KiB per
classified diagnostic channel, 30 second absolute execution deadline. Existing
process tree child/depth/call/blob quotas and serving record/history limits also
apply. Reservations and consumed launch/input/return resources survive failure,
cancellation, restart and lost acknowledgement; no refunds or automatic relaunch.

Native protected records and existing affine knowledge joins own authority and
release. Process journals only attach the reserved child and own tree quotas.
There is no transaction across those stores. Sensitive bytes wait for observed
enforced launch and a committed child observation. Parent knowledge and an
exact stable return intent commit before delivery. Redelivery rechecks current
parent, contract, capability and recipient context.

Local portability and native refusal gates run on Darwin arm64. Real Linux
acceptance ran separately on the task-owned OCI Ubuntu 24.04 x86_64 host,
Linux 6.17.0-1020-oracle, Rust 1.94.1, with native cage probes and measured
interpreter-free static PIE reader, helper and nine adversarial images.
All ten required Linux recovery cases passed on the final source binding.
All 46 local gates passed on that same binding; all six P5 tasks are accomplished
and all ten ISO obligations verified. Cross compilation alone never satisfies Linux acceptance.
