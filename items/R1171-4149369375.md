**<sub><sub>![P2 Badge](https://img.shields.io/badge/P2-yellow?style=flat)</sub></sub>  Verify bundled fonts against their digest manifest**

When a bundled TTF or OFL file is accidentally replaced or modified, this check only regenerates the PDF and compares its extracted text; it never validates the byte counts or SHA-256 values recorded in `tools/fonts/sources.json`. In particular, altered license text and many font substitutions leave PDF text unchanged, so CI can pass while the repository no longer contains the hash-pinned upstream assets claimed by `tools/fonts/README.md` and `SUBMISSION.md`; validate every manifest entry before building.
