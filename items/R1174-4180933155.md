**<sub><sub>![P1 Badge](https://img.shields.io/badge/P1-orange?style=flat)</sub></sub>  Namespace provider-supplied request IDs**

Using a provider call ID unchanged does not satisfy the preceding cross-payload uniqueness requirement: if a provider reuses an ID in a later turn within the same request namespace, durable admission either conflicts or, when the normalized binding is unchanged, replays the earlier terminal result without dispatching the new call. Prefix or bind provider IDs with the retry-stable payload identity just as synthesized IDs are, while preserving stable IDs for retries of the same turn.
