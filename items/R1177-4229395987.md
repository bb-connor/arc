**<sub><sub>![P2 Badge](https://img.shields.io/badge/P2-yellow?style=flat)</sub></sub>  Ignore fenced examples when collecting case definitions**

When `CASES.md` contains a fenced example row such as `| Q99 | example |`, this raw regex counts Q99 as a real definition. A Q99 reference elsewhere then passes even though the rendered case table has no Q99 entry, undermining the guarantee that every referenced acceptance case is defined exactly once. Strip fenced code before collecting rows or restrict definitions to the actual case table.
