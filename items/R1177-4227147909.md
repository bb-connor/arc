**<sub><sub>![P1 Badge](https://img.shields.io/badge/P1-orange?style=flat)</sub></sub>  Inherit workspace lints in the new custody crate**

The proposed `chio-key-custody` manifest omits `[lints] workspace = true`, so it does not inherit the workspace's `clippy::unwrap_used` and `clippy::expect_used` denies; `cargo clippy -- -D warnings` does not enable restriction lints that remain `allow` by default. Add the workspace lint table to this new crate so production key-handling code cannot introduce unchecked panics.
