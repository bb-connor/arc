**<sub><sub>![P2 Badge](https://img.shields.io/badge/P2-yellow?style=flat)</sub></sub>  Do not treat top-level indented code as a fence**

When a program document has a top-level line indented four spaces containing three backticks, followed by `[broken](MISSING.md)` at column zero and another indented backtick line, CommonMark treats the indented lines as code blocks and the link as ordinary Markdown. This regex accepts unlimited opening indentation, removes the entire span as a fenced block, and lets the broken link pass the gate. Parse container-aware fences or reject top-level fence indentation beyond three spaces.
