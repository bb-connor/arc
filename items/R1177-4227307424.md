**<sub><sub>![P1 Badge](https://img.shields.io/badge/P1-orange?style=flat)</sub></sub>  Wire authority revocations into API Protect**

The installed door starts API Protect without `--revocation-db` or a control-plane connection, even though the trust service records operator revocations in `%S/chio/revocations.sqlite3`; the macOS argument list has the same omission. API Protect returns an empty operator-revocation set when that option is absent, so a capability revoked through `chio trust revoke` remains usable at the protected upstream until it expires. Pass the authority's revocation store into the door and qualify revocation before dispatch.
