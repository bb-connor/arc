**<sub><sub>![P1 Badge](https://img.shields.io/badge/P1-orange?style=flat)</sub></sub>  Keep the trust service token out of same-UID storage**

In the user-session profile, an untrusted agent or other process running under the enrolled UID can read this mode-0600 file and recover `CHIO_TRUST_SERVICE_TOKEN`; that token authenticates the inbox list, approve, and deny routes, so the process can approve its own presentation and mint authority without the operator review this flow promises. Store the admin token behind a separately authenticated custody or broker boundary rather than in a same-UID-readable environment file.
