**<sub><sub>![P2 Badge](https://img.shields.io/badge/P2-yellow?style=flat)</sub></sub>  Reject return types with an empty value domain**

`Enum` permits an empty list and `Integer` does not require `min <= max`, so a malformed return contract can make I23's cardinality `N` zero or negative. The required `bit_length(N - 1)` is then undefined and an implementation may underflow or panic instead of rejecting the policy. Validate these invariants when loading the contract, before any projection or capacity calculation.
