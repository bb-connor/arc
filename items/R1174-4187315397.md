**<sub><sub>![P1 Badge](https://img.shields.io/badge/P1-orange?style=flat)</sub></sub>  Seed legacy contexts as unknown before enabling gating**

Existing contexts may already have consumed external tool outputs that were never written to the P4 journal, since section 5 explicitly identifies output delivery as currently untracked. Treating a legacy record with both flags false as trusted, and leaving a context with no legacy rows as an empty trusted state, converts missing history into proof of trust; after migration such a previously injected context can satisfy a `Trusted` requirement. Seed every pre-tracking live context as `unknown`, or require a fresh isolation epoch, unless complete mediated history can be proven.
