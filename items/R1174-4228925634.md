**<sub><sub>![P2 Badge](https://img.shields.io/badge/P2-yellow?style=flat)</sub></sub>  Bound evidence capacity across hosted sessions**

When hosted clients can create many sessions during a receipt-store or signing failure, each session gets a separate kernel, pool, and buffer, while this rule explicitly requires no host-wide session or evidence bound. After one in-flight call per session reaches the post-effect failure path, each kernel can retain a buffered fault record behind its own latch, so the per-kernel limit does not bound aggregate memory or retained evidence and an attacker can exhaust the host by continually opening sessions. Add a host-wide slot budget or a hard hosted-session limit shared by these pools.
