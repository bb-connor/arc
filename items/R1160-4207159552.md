**<sub><sub>![P2 Badge](https://img.shields.io/badge/P2-yellow?style=flat)</sub></sub>  Decode reconcile arguments with document semantics**

When `/v1/evaluate` authorizes ordinary JSON arguments containing a noncanonical decimal spelling such as `0.50`, it succeeds via `decode_arguments`, but this `/v1/reconcile` path rejects the same arguments because `input::decode` applies signed/canonical validation to the entire envelope. The tool server therefore cannot settle the reserved hold even with the valid nonce and exact authorized arguments; use the mixed signed/unsigned decoder here so the nonce remains strict while `arguments` retain document semantics.
