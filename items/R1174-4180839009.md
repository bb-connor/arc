**<sub><sub>![P1 Badge](https://img.shields.io/badge/P1-orange?style=flat)</sub></sub>  Include the artifact delivery in the observation ID**

When the same artifact version is read by two contexts in one tenant and isolation epoch, both reads derive the same `observation_id` from the artifact version digest. Because the uniqueness key omits the principal, lineage, and session, the second context's insert is ignored and its summary heads never receive the artifact's influence; that context can consequently remain trusted and pass a later integrity-gated call. Derive the ID from a delivery/read record (including its destination context), while keeping retries of that one delivery stable.
