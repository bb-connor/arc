**<sub><sub>![P1 Badge](https://img.shields.io/badge/P1-orange?style=flat)</sub></sub>  Do not rely on a process latch for offline stops**

When the host is down and the offline CLI encounters a full journal or a failed intent write, this rule returns `process_only`, but the only process latch is in the short-lived CLI process. Once the CLI exits, no serving process retains that latch and the next boot has neither a journal entry nor a stop record, so work can resume despite the purported offline stop. The offline path must persist an enforceable intent or report that no stop is in force rather than using the online-only latch fallback.
