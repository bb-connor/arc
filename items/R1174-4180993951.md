**<sub><sub>![P1 Badge](https://img.shields.io/badge/P1-orange?style=flat)</sub></sub>  Let a verified endorsement satisfy the authoritative check**

In a tainted context, this crossing checks only `satisfies(state, requirement)`, and the early guard likewise reads only the context state. Because I21 explicitly leaves that state unchanged, even a valid exact `IntegrityEndorsement` with the current `influence_basis` still fails both checks, so the only advertised remedy for `Trusted` and `ProviderOnly` faults can never authorize its continuation. Carry the verified endorsement into both checks and atomically validate its exact action, principal, and current influence basis before allowing that one call.
