**<sub><sub>![P2 Badge](https://img.shields.io/badge/P2-yellow?style=flat)</sub></sub>  Define an ID for session terminal events**

When a negotiated `chioEvents` session terminates, its `Terminal { reason }` comes from the dedicated `TerminalSlot`, not from a client-created subscription, so it has no `subscription_id`. This rule nevertheless requires that field on every control-subject event, and `Lifecycle` is explicitly a control subject, making the terminal frame impossible to serialize according to the declared wire shape. Define a separate session-terminal envelope or make `subscription_id` absent for that event while keeping it mandatory for `SubscriptionEnded`.
