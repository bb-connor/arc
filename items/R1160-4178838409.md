**<sub><sub>![P2 Badge](https://img.shields.io/badge/P2-yellow?style=flat)</sub></sub>  Avoid recursively copying every enclosing JSON subtree**

For a near-16 MiB process response containing deeply nested single-element arrays or objects, each recursive call reparses the entire remaining subtree into owned `Box<RawValue>` values while all ancestor containers remain live. At the permitted depth of 64 this turns a bounded document into depth-multiplied allocation and repeated scans that can exhaust memory in the offline verifier; perform one duplicate-aware traversal over the original input, or otherwise avoid retaining an owned copy at every level.
