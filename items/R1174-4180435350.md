**<sub><sub>![P2 Badge](https://img.shields.io/badge/P2-yellow?style=flat)</sub></sub>  Sign container launch evidence after start succeeds**

The runner is instructed to sign a record containing `started_at` after pre-start inspection but before issuing the start request. If the subsequent start fails, a valid signed record has already claimed a launch and cannot simply be changed to `BootstrapFailed`; the timestamp also cannot truthfully represent a successful start yet. Sign the success record only after the exact inspected container starts, and emit a distinct signed failure record when start fails.
