**<sub><sub>![P2 Badge](https://img.shields.io/badge/P2-yellow?style=flat)</sub></sub>  Reject duplicate provider call IDs within one lift**

Two calls in the same provider payload with the same `provider_call_id` also share the same `lift_id`, so this formula gives them identical request IDs despite rule 1 requiring uniqueness across every lifted payload. If their bindings differ, the second call conflicts with the first durable identity; if they are identical, it can replay the first result instead of representing the second call. Either incorporate the batch position into provider-backed IDs or reject duplicate provider call IDs during lift.
