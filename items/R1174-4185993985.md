**<sub><sub>![P2 Badge](https://img.shields.io/badge/P2-yellow?style=flat)</sub></sub>  Update the cross-spec decision to require binding.v3**

This cross-spec decision still directs the program to use `binding.v2`, even though the child spec explicitly replaces it before implementation with `binding.v3`, which additionally binds the authenticated request namespace and submitted capability. Following the umbrella decision would omit those fields and reintroduce response swapping between byte-identical invocations under different namespaces or capabilities. Name `binding.v3` and its namespace/capability fields here so the program has one authoritative binding version.
