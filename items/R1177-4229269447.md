**<sub><sub>![P2 Badge](https://img.shields.io/badge/P2-yellow?style=flat)</sub></sub>  Decode entities before retired-phrase matching**

When visible Markdown or SVG text encodes any character as an HTML/XML entity, for example `Agents that pay each&#32;other` or `answ&#101;r`, the rendered copy contains the exact retired phrase but `visible_text` leaves the entity syntax intact, so the literal regex misses it. Decode character references before whitespace normalization and matching, with Markdown and SVG regression cases, so encoded public copy cannot bypass the positioning gate.
