**<sub><sub>![P2 Badge](https://img.shields.io/badge/P2-yellow?style=flat)</sub></sub>  Exclude footnote definitions from link targets**

When a program document uses a GitHub-style footnote such as `[^note]: This is explanatory text.`, `REF_DEF` classifies it as a reference-link definition with destination `This`, and the link checker reports that word as a missing file. Valid documentation with ordinary footnotes therefore fails the program gate; exclude `^`-prefixed labels from link definitions or parse footnotes separately, and add a regression fixture.
