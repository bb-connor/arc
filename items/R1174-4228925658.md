**<sub><sub>![P2 Badge](https://img.shields.io/badge/P2-yellow?style=flat)</sub></sub>  Preserve bearer-authenticated process cancellation**

For a process or ancestor closing its own `ProcessTree`, the table promises compatibility with the existing worker `cancel` operation, but the following rule requires every non-operator closer to produce a signed close-request artifact. Workers authenticate with a 256-bit bearer credential and the existing cancel request has no signing key or signed envelope, so an implementation cannot satisfy both requirements without either breaking worker cancellation or silently exempting this path from the stated authorization protocol. Define the worker-credential-authenticated variant explicitly, or add a negotiated signed request to the worker ABI.
