**<sub><sub>![P2 Badge](https://img.shields.io/badge/P2-yellow?style=flat)</sub></sub>  Allow containment to be disabled during an existing stop**

A stop created with the default `allow_containment = true` cannot later be tightened when the active-defense authorities become suspect: S2 makes every stop-over-stopped request a no-op, so the new `allow_containment = false` value is never committed. The only available state transition is to resume first, which creates precisely the unsafe running window this option is meant to avoid. Permit a stopped-to-stopped epoch when stop policy changes, or separate containment policy from the alternating state chain.
