**<sub><sub>![P1 Badge](https://img.shields.io/badge/P1-orange?style=flat)</sub></sub>  Authenticate bootstrap trust assertions**

When a fresh context treats a task, seed, or other bootstrap contribution as trusted, this is the only specified assertion representation, but it carries merely a roster `signer` identifier with no signature or signed-envelope type; `BootstrapKind` is also undefined, and the schema-impact list omits `chio.bootstrap-trust-assertion.v1`. An implementation therefore cannot authenticate or consistently decode the evidence that removes `External` influence, and trusting this structure as written lets a fabricated assertion make attacker-controlled bootstrap bytes satisfy `Trusted`. Define the signed envelope, closed contribution-kind vocabulary, verification key, and schema, rejecting unsigned or malformed assertions.
