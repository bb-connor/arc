When the legacy reader has scanned 256 deferred operations, this probe treats any later operation as unresolved work. A later terminal operation without a quarantined deferral is excluded from recovery candidates, but the probe still makes `list_recoverable` return `Unavailable` instead of an empty result. The admission-authority RPC propagates that error, so a valid recovery listing fails.
