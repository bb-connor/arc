**<sub><sub>![P2 Badge](https://img.shields.io/badge/P2-yellow?style=flat)</sub></sub>  Add the no-input case to action_ok**

When a contract has input slots but selects its `no_input` row for a trusted context, I22a says the call binds no inputs, yet this predicate always requires `inputs_bound`, which in turn requires the input count to equal the nonzero slot count. The advertised normal trusted-context path therefore cannot satisfy the formal admission invariant and will be denied; add an explicit no-input branch that requires zero bound inputs and no unconsumed slot-matching returns.
