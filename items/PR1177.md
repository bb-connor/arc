1. **P1 — M1 implementation instructions contradict the accepted custody design.** [2026-10-08-m1-cooperate-0.md:23](https://github.com/bb-connor/arc/blob/9fa3843778c9/docs/superpowers/plans/2026-10-08-m1-cooperate-0.md#L23) says the plan needs nothing from #1160; lines 8 and 54 prescribe new seed-loader plumbing, and line 39 selects login Keychain. However, ADR-0038:181–183 and the macOS annex:71–78 require extending #1160’s `signing_custody` and selecting data-protection Keychain for user sessions. The integration branch already contains the custody owner and its bounded, identity-checked reads. This plan remains executable-looking without a superseded notice.

2. **P1 — The issuance inbox cannot recover a lost approval response.** [2026-10-08-m1-cooperate-0.md:1706](https://github.com/bb-connor/arc/blob/9fa3843778c9/docs/superpowers/plans/2026-10-08-m1-cooperate-0.md#L1706) issues the capability, stores only its ID, then returns the signed capability. Repeated approval rejects non-pending requests at lines 1659–1663; the route table contains no holder pickup route. On `origin/main`, `passport_handlers.rs:1128` consumes the challenge before issuance. Losing the response therefore prevents recovery through the original request, contradicting NORTH-STAR-FLOWS:488–492 and its required holder pickup at line 178.

3. **P1 — The proposed end-to-end test does not verify the door’s receipts.** [2026-10-08-m1-cooperate-0.md:2184](https://github.com/bb-connor/arc/blob/9fa3843778c9/docs/superpowers/plans/2026-10-08-m1-cooperate-0.md#L2184) exports the trust-control `receipts.sqlite3` before any protected tool call. The separate door test writes `tool-receipts.sqlite3` at line 2291 and never exports it. `origin/main`’s `evidence_export.rs:1187–1190` reads the selected database only. Passing these tests cannot establish offline verification of the allowed and denied door calls required by NORTH-STAR-FLOWS:178–180.

4. **P1 — The macOS installer replaces the environment variable’s name.** [2026-10-08-m1-cooperate-0.md:2071](https://github.com/bb-connor/arc/blob/9fa3843778c9/docs/superpowers/plans/2026-10-08-m1-cooperate-0.md#L2071) globally substitutes `CHIO_TRUSTED_ISSUER_KEY`. Line 2043 uses that string for both the plist key and its placeholder value. Reproducing the substitution changes both to the public-key hex, removing the required environment variable. `origin/main`’s `cli/runtime.rs:580–593` reads the literal variable name, so B’s door will not receive the configured trusted issuer.

5. **P1 — Case checking silently accepts undefined cases.** [scripts/check-native-host-docs.py:39](https://github.com/bb-connor/arc/blob/9fa3843778c9/scripts/check-native-host-docs.py#L39) excludes `H09` and `C20` from recognition; line 265 also checks only range endpoints.
