**<sub><sub>![P1 Badge](https://img.shields.io/badge/P1-orange?style=flat)</sub></sub>  Bind each discharge token to its obligation**

`PostEffectDischarge` records only a receipt or operation id and carries no binding to the request held by `PostEffectObligation`. With two live evaluations, a caller can therefore use the token produced for evaluation A to discharge evaluation B; Rust's move checks pass even though B has no committed terminal evidence. Include the request binding or a per-obligation nonce in every discharge token and verify it in `discharge`.
