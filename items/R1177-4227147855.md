**<sub><sub>![P2 Badge](https://img.shields.io/badge/P2-yellow?style=flat)</sub></sub>  Reject unknown custody policy values**

When `CHIO_KEY_CUSTODY` is misspelled, non-Unicode, or set to any value other than exactly `required`, this branch silently selects `AllowFiles`; an operator intending mandatory OS custody can therefore start the service with plaintext seed files without any configuration error. Parse unset as the development default, but reject every unrecognized configured value so a malformed security policy cannot weaken custody.
