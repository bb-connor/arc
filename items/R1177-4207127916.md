**<sub><sub>![P2 Badge](https://img.shields.io/badge/P2-yellow?style=flat)</sub></sub>  Represent every reviewed scope binding as typed data**

The start summary is required to expose the operator/authority identity, policy, provider/account reference, verification plan, and publication destination, but this response has no fields for most of those bindings and substitutes an unconstrained array of display strings. A server can therefore return a valid `scope.get` result whose digest commits a changed native policy or destination without giving the client a typed value it can reliably render and compare before enabling Start; add explicit bounded fields for all security-relevant bindings and reject unavailable ones rather than relying on `selection_summary`.
