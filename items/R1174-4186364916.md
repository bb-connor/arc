M7a now increments `attempt_generation` after a durable `release_abandoned` and requires the replacement release to use a fresh key, but T6 still requires every release of the hold to carry the same `hold_release_key`. An implementation or extracted proof satisfying this theorem must either reject the required retry or reuse the definitively rejected/fenced key and strand the hold; scope key equality to one attempt generation and assert rotation after abandonment instead.
