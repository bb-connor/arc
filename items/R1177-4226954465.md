**<sub><sub>![P2 Badge](https://img.shields.io/badge/P2-yellow?style=flat)</sub></sub>  Make OS-custody key initialization atomic**

When two `chio key init` processes target the same absent OS reference, both can pass the earlier read, generate different keypairs, and execute this write; the backend may replace the first value while both callers report their own public key as successfully created. That can publish an organization DID whose private key is immediately lost. Use an add-if-absent backend operation or serialize and re-read atomically, and add a barrier-synchronized initialization test.
