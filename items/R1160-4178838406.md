For remote discovery, this delegates to `discover_spec`, whose general upstream contract permits a 64 MiB response and calls `resp.text()` before this function applies `MAX_OPENAPI_BYTES` (8 MiB). An upstream can therefore force allocation and UTF-8 conversion of up to eight times the accepted spec size on every startup probe before the document is rejected; apply the OpenAPI-specific byte limit while streaming the response and decode only the bounded bytes.
