**<sub><sub>![P1 Badge](https://img.shields.io/badge/P1-orange?style=flat)</sub></sub>  Define an encodable legacy migration transition**

When startup finds an existing `semantic-stop:{scope}` value, S5 requires an epoch-1 record using `LegacySemanticStop` and `requested_via: Migration`, and S2 even defines separate Migration field rules. However, `StopTransition` has no Migration variant; encoding it as `Stop` is also invalid because the Stop verifier requires contributors and forbids both `Migration` and `LegacySemanticStop`. The legacy stop therefore cannot be migrated into a valid head, potentially either blocking upgrades or losing the stopped state when the old checks are replaced. Add a migration variant or explicitly define a valid Stop encoding for this record.
