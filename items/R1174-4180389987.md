**<sub><sub>![P1 Badge](https://img.shields.io/badge/P1-orange?style=flat)</sub></sub>  Fence ordinary output release during closure**

This claimed-complete crossing table omits the ordinary caller and native output-release checkpoints (`terminal.rs:126` and `native_output.rs:396`, which the sibling stop spec explicitly treats as separate crossings). If closure commits after `DispatchCommitted` but before either release, the drain classifies the operation as post-dispatch and retains it, yet no closure fence is rechecked before the bytes leave. Add both release crossings and make them consult the applicable closure fence so closing a session, process tree, or capability subtree can actually withhold output that remains in Chio custody.
