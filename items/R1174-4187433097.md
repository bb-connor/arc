**<sub><sub>![P1 Badge](https://img.shields.io/badge/P1-orange?style=flat)</sub></sub>  Treat untracked legacy artifacts as unknown**

Fresh evidence after adding the unknown seed for live contexts is that a context created after migration can still read a pre-migration artifact whose stored flags are both false; this rule adds neither an origin nor `unknown`, and I1 consequently permits the context to remain `Trusted`, even though that artifact may have been produced from the same unjournaled tool output identified in the next line. Project legacy artifacts with missing provenance as unknown unless their complete mediated history is independently proven.
