**<sub><sub>![P2 Badge](https://img.shields.io/badge/P2-yellow?style=flat)</sub></sub>  Create signing obligations for rollover records**

When the automatic rollover in S6 commits, it is a `Rollover` transition and therefore falls into neither signing branch here: only Stop/Restrict create a pending post-commit obligation, while only Resume/Relax sign in-transaction. If signing is unavailable at rollover, the new generation can consequently have no artifact or pending obligation, and a later resume can produce a Running head despite the claimed invariant that its whole chain is signed. Include rollover in the commit-first obligation and reconciliation path.
