**<sub><sub>![P2 Badge](https://img.shields.io/badge/P2-yellow?style=flat)</sub></sub>  Escape values before rendering launchd plists**

When the state directory or configured URL contains a legal replacement character such as `&` or `#`, these `sed` expressions either expand `&` to the placeholder text or terminate the substitution at `#`, producing wrong paths or aborting installation. XML metacharacters can also make the generated plist invalid. Render the plist with a plist-aware tool or escape both sed replacement syntax and XML content, and validate the generated files rather than only the source templates.
