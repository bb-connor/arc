**<sub><sub>![P1 Badge](https://img.shields.io/badge/P1-orange?style=flat)</sub></sub>  Exempt prior-effect settlement from permanent authority fences**

`ExternalPrepare { Settle }`, federation co-signing, and channel release publication receive the temporary-stop `Settle` disposition, but they still run both the closure-fence and revocation checks. If a capability is revoked or its authority space is permanently closed after the underlying effect commits but before capture, release, co-signing, or publication, every later settlement attempt is refused forever, contradicting the teardown invariant that earned work remains payable and agreed escrow transitions continue. Apply the same subject-before-cut test to closure and revocation for these settlement kinds while continuing to deny new authorizations.
