**<sub><sub>![P1 Badge](https://img.shields.io/badge/P1-orange?style=flat)</sub></sub>  Carry the release authority through acknowledgement**

`ReleaseAuthorized` contains the authority and evidence, but after emitting `ReleaseHold` the only success event available is `EffectAcknowledged { effect, committed_version }`, and `AdmissionState` has no pending-release field. The pure transition therefore cannot perform the promised `unknown_hold = Released(authority)` update on acknowledgement; updating it before the port commits would falsely record a failed release, while leaving it `Frozen` permits repeated release attempts. Add a `Releasing` state that retains the authority or include the release authority in a typed acknowledgement.
