**<sub><sub>![P2 Badge](https://img.shields.io/badge/P2-yellow?style=flat)</sub></sub>  Reserve sequence zero for the no-cause sentinel**

The cause cell assigns `0` the special meaning “no cause,” but the `InboundSeq` API never requires sequences to start at 1 or otherwise forbids zero. A natural zero-initialized monotonic counter can therefore assign the first request sequence 0, making its response and server requests indistinguishable from background events; the response may bypass its slot and leave the POST waiting indefinitely. Specify a nonzero initial value and reject zero on construction as well as overflow.
