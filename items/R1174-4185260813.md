**<sub><sub>![P1 Badge](https://img.shields.io/badge/P1-orange?style=flat)</sub></sub>  Bind selector inputs to specific return records**

When a context contains two committed returns governed by the same `ReturnContractDigest` but with different values, this contract identifies only the contract type, not which delivery supplies the selector input or its ordering. Crossing check 4 therefore cannot compute a unique expected action and an implementation could select whichever historical value makes the requested action pass, defeating the promised value-to-action mapping. Bind the call to stable confined-return evidence IDs with defined cardinality/order, and reject missing or ambiguous inputs.
