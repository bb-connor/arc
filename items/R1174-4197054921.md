**<sub><sub>![P2 Badge](https://img.shields.io/badge/P2-yellow?style=flat)</sub></sub>  Persist rebased subscription end event IDs**

When Part B restores a persisted `Ended` subscription, H5a requires assigning its `end_event_id` in the restored generation and re-signing that marker before the session is served, but this instruction persists the record with only `resume_generation` changed and explicitly carries every subscription over unchanged. Following A17 therefore either requeues the old-generation event ID, violating the monotonic generation scheme, or emits a fresh ID that is not in the durable marker, so a crash and replay-past cleanup use the wrong ID. Include all rebased `Ended` marker updates in this single generation persist.
