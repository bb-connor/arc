## Brief

Found by the planner-side cross-vendor review of PR #1160 at fd8bfdc947bb (kernel reviewer): P2, confirmed. The owner deferred it to after the #1160 merge (2026-10-09); fix it on integration/beta-next.

**Finding.** chio-runtime facade hook does not forward revalidate_reserved_operation, so operation-owned reserved-caller re-presentation always fails

**Where.** `crates/kernel/chio-runtime/src/admission_hook.rs:127` (introduced by 2c5188e8a)

**Scenario.** A host builds chio_runtime::ChioRuntimeAdmissionHook::new(profile, sqlite_store).with_operation_owned_runtime_replay(binding), which the facade README says preserves the core hook's operation-owned contracts. A caller-delivered (caller-report attempt) operation is admitted and reaches ReadyToDispatch. When the caller re-presents it, ChioKernel::evaluate_operation_owned_runtime_hook sees ReadyToDispatch plus is_caller_report_attempt and calls revalidate_reserved_caller_runtime, which invokes hook.revalidate_reserved_operation. The facade impl overrides ten trait methods but not this one, so the trait default runs and returns Err(DurableAdmission("reserved caller runtime revalidation is unsupported")). The core hook (chio-runtime-core admission_hook.rs:810) implements it correctly. Result: every reserved caller operation through the public facade is refused (fail-closed liveness loss on the durable caller-custody path). The core hook used directly by chio-cli process_host/swarm.rs does not have this problem.

**Evidence at fd8bfdc.** fd8bfdc crates/kernel/chio-runtime/src/admission_hook.rs:127-209 forwards name, runtime_participant_binding, evaluate_operation_owned, evaluate, release_reserved, requires_dispatch_revalidation, enforces_swarm_authority, revalidate_before_dispatch, revalidate_operation_owned_before_dispatch and revalidate_operation_owned_for_native_capture, but not revalidate_reserved_operation. Trait default: crates/kernel/chio-kernel/src/kernel/runtime_admission.rs:124-133 `fn revalidate_reserved_operation(...) { Err(KernelError::DurableAdmission("reserved caller runtime revalidation is unsupported".into())) }`. Caller: crates/kernel/chio-kernel/src/kernel/admission_coordinator/runtime_acquisition.rs:349-355 dispatches to revalidate_reserved_caller_runtime, which at runtime_reserved.rs:70-73 calls hook.revalidate_reserved_operation. Core implementation that the facade fails to delegate: crates/kernel/chio-runtime-core/src/admission_hook.rs:810-832.

Line numbers are from fd8bfdc; re-locate them on the current base first.
