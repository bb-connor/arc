R6 requires linked-workflow creation and capture to refuse whenever an issuance freeze covers the predecessor's tenant and lineage, but this capture rule consults the issuance-freeze authority only for `Delegator` remedies. A `ReceiverIssuer`, `AllocationHolder`, or `Payer` successor minted before a freeze is installed can therefore capture afterwards because its one ordinary issuance check has already passed; query the freeze for every resolver class at both security boundaries, using the appropriate issuance operation.
