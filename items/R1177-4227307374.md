**<sub><sub>![P1 Badge](https://img.shields.io/badge/P1-orange?style=flat)</sub></sub>  Render the actual macOS executable path**

On the documented arm64 macOS path, the prerequisite only builds `chio`, and this installer never copies it into `/usr/local/bin`; Cargo normally leaves the binary under `target`, while Homebrew on Apple Silicon commonly uses `/opt/homebrew/bin`. The generated LaunchAgent therefore cannot start on a machine following the runbook unless the operator performs an undocumented installation step. Install the binary or substitute a validated executable path into both plists.
