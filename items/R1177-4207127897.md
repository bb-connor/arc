**<sub><sub>![P2 Badge](https://img.shields.io/badge/P2-yellow?style=flat)</sub></sub>  Reject duplicate scope-limit dimensions**

The `limits` array has room for 16 entries but only seven dimensions and does not require dimensions to be unique, so a schema-valid `scope.get` response can contain contradictory entries such as two `wall_ms` limits with different values or enforcement states. Because this is the summary shown before Start and committed by `reviewed_scope_digest`, clients have no unambiguous limit to present or enforce; add a semantic uniqueness check (with a negative fixture) or model the dimensions as uniquely keyed properties.
