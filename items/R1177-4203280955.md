**<sub><sub>![P2 Badge](https://img.shields.io/badge/P2-yellow?style=flat)</sub></sub>  Install the dependency needed for date-time validation**

The documented clean environment installs only `jsonschema==4.21.1`, but the schemas rely on `format: date-time` for health observations, review expiry, and release timestamps. `FormatChecker` silently accepts that format when the optional `rfc3339-validator` dependency is absent; the [jsonschema documentation](https://python-jsonschema.readthedocs.io/en/stable/validate/#validating-formats) explicitly lists that dependency and warns that missing format dependencies make validation succeed. Install the `format` or `format-nongpl` extra and add an invalid-date fixture so the advertised format checking actually runs.
