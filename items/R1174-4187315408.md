**<sub><sub>![P1 Badge](https://img.shields.io/badge/P1-orange?style=flat)</sub></sub>  Remove the receipt ID from its own metadata commitment**

`commitment_ref` is receipt metadata, and the authoritative receipt ID is the SHA-256 of canonical `ChioReceiptIdInput`, which includes that metadata (`crates/core/chio-core-types/src/receipt/body.rs`, lines 180-243). This formula therefore requires the final `receipt_id` to compute metadata that must already exist to compute that same ID, making every integrity-bearing allow receipt an unconstructible hash fixed point. Bind the reference to independently available values, such as a receipt nonce or a canonical pre-ID body that explicitly excludes `commitment_ref`.
