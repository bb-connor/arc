**<sub><sub>![P2 Badge](https://img.shields.io/badge/P2-yellow?style=flat)</sub></sub>  Validate user units without requiring a live user manager**

When this test runs in an Ubuntu CI runner or container without a logged-in user systemd instance, `systemd-analyze --user verify` fails before validating the unit with `Failed to lookup RuntimeDirectory path` and `Failed to initialize manager`. I reproduced this with systemd 255; its help describes `--user` as “Operate on user systemd instance,” so merely detecting the binary is insufficient. Use a syntax-validation mode that does not initialize the user manager, or provision the required user runtime before invoking it.
