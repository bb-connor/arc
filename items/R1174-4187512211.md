**<sub><sub>![P1 Badge](https://img.shields.io/badge/P1-orange?style=flat)</sub></sub>  Define an opening incident for migrated stopped scopes**

When startup converts a legacy enabled semantic stop into the `Migration` record specified by S5, the resulting stopped scope has no opening `Stop`. The default `OperatorPair` form nevertheless requires `stopper_epoch` to name that opening `Stop`, and `SamePrincipalAfter` likewise requires its observation, so after S28 removes the shared-credential path neither form can authorize a resume of this migrated scope. Treat `Migration` as an incident opener with defined stopper and cooldown semantics, or add a migration-specific resume basis.
