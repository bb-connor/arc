Because `enforcement` and `value` are independent and `value` explicitly accepts `null`, a `scope.get` response such as `{"dimension":"wall_ms","enforcement":"enforced","value":null}` is schema-valid. This is the exact limit summary displayed before Start and bound by `reviewed_scope_digest`, so clients can present a limit as enforced without any actual ceiling; add a conditional semantic/schema check and an invalid fixture requiring a safe integer whenever enforcement is `enforced`.
