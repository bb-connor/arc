**Finding.** Execution-nonce and nonce-preflight tables are outside the admission canonical schema catalog and created with IF NOT EXISTS, so a mis-shaped or trigger-less table is adopted silently

**Where.** `crates/platform/chio-store-sqlite/src/admission_operation_store/schema.rs:991`

**Scenario.** admission_operation_schema_catalog compares sqlite_schema entries only for the admission_operation*, obligation_*, credit_exposure_*, replay and security participant namespaces; admission_execution_nonce_issuances/_reservations/_transitions and admission_nonce_preflight_holds match none of the globs. At on_disk == 36 open only runs verify_admission_operation_invariants (orphan and row-binding checks, not shape/trigger checks), and migrate_schema runs the nonce DDL with CREATE TABLE IF NOT EXISTS without a pre-migration absence check. A restored or repaired database whose nonce table lacks nonce_id UNIQUE or the _immutable/_no_delete triggers would serve undetected, after which the same nonce could be reserved twice or its history deleted. Requires out-of-band modification of the database; confirm by checking that no other verifier compares these tables' sqlite_schema to the compiled DDL (none found).

**Evidence at fd8bfdc.** schema.rs:984-1018 catalog WHERE clause (no 'admission_execution_nonce*' or 'admission_nonce_preflight*' globs); schema.rs:77-78 'if on_disk == ADMISSION_OPERATION_SUPPORTED_SCHEMA_VERSION { return verify_admission_operation_invariants(connection); }'; schema.rs:202-207 'transaction.execute_batch(include_str!("../admission_operation_nonce.sql"))' and nonce_preflight.sql; admission_operation_nonce.sql:3-70 'CREATE TABLE IF NOT EXISTS ... nonce_id TEXT NOT NULL UNIQUE' and triggers.
