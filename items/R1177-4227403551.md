**<sub><sub>![P2 Badge](https://img.shields.io/badge/P2-yellow?style=flat)</sub></sub>  Retry failed desktop notifications**

When `osascript` or `notify-send` is missing, exits nonzero, or temporarily cannot reach the desktop session, this implementation discards the failure, while `announce_new` has already inserted the challenge ID into `seen`. The request can remain pending indefinitely, but every later poll suppresses another notification, so the operator may never learn that review is required. Return notification success and mark an ID seen only after delivery succeeds, while reporting failures.
