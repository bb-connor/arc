**<sub><sub>![P1 Badge](https://img.shields.io/badge/P1-orange?style=flat)</sub></sub>  Authenticate browser requests to the controller**

When an enrolled workbench session is live and the user visits a malicious origin, this requires the browser to authenticate the controller but does not require the genuine controller to reject cross-origin requests carrying ambient cookies or other live session state. The sole browser acceptance case at line 273 tests an impostor server and replay after takeover, not CSRF or cross-site WebSocket requests against the genuine endpoint, so a blind work or stop command could be accepted under the victim's session. Require non-ambient per-request client proof plus origin binding, add this negative case, and disable the route when that binding is unavailable.
