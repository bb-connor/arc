This makes the fixture directory the canonical editable plugin source and says a separate release repository needs an ownership transfer, but no later task performs that transfer, creates a pinned public plugin artifact, or installs the fixture as a plugin. The P7 `PKGBUILD` intentionally packages only the backend, units, desktop entry, and menu fragment, while its clean-install acceptance requires public artifacts, so a clean host cannot obtain the actual `manifest.json`/QML surface needed to qualify `observe-v1`; add an explicit plugin publication and pinning task before the clean-install gate.
