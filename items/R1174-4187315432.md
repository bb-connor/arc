**<sub><sub>![P1 Badge](https://img.shields.io/badge/P1-orange?style=flat)</sub></sub>  Preserve stopper identities across stopped rollovers**

After an automatic rollover of a stopped scope, the current head has `ChainRollover` as its authorizer and no contributors, but this rule never defines whether `stopper_epoch` must point through that head to the original stop or which earlier `Restrict` contributors count. An implementation that checks the expected head's authorizer sees no operator principal and can let the original stopper resume immediately, bypassing the default two-person rule. Define the incident's preserved stopper set across `Restrict` and `Rollover` records and require the resumer to differ from every principal in that set.
