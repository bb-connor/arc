**<sub><sub>![P2 Badge](https://img.shields.io/badge/P2-yellow?style=flat)</sub></sub>  Reserve a generation for terminal fencing**

When a stored record has `resume_generation == 2^32 - 2`, this check permits restore to persist and serve generation `g == 2^32 - 1`. Any later expiry, close, subscription-authority loss, or low-bit exhaustion then needs a terminal generation strictly greater than `g`, but that value is not representable, so A30/A31 can never complete the terminal fence and the session store remains unavailable indefinitely. Refuse activation one generation earlier or use a terminal epoch with additional headroom.
