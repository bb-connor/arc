**<sub><sub>![P2 Badge](https://img.shields.io/badge/P2-yellow?style=flat)</sub></sub>  Make the automated release trigger release-tagged**

Retargeting `release-tagged.yml` is insufficient for the automated preview path: `.github/workflows/release-binaries.yml:691-698` creates the GitHub Release with the action's default `github.token`, while `release-tagged.yml:13-15` waits for the resulting `release.published` event. GitHub documents that events created with `GITHUB_TOKEN` do not start another workflow run, except for dispatch events, so the compatibility-row workflow remains silent after an automated release; use a GitHub App/PAT or chain it with `workflow_run` or an explicit dispatch. [GitHub `GITHUB_TOKEN` trigger behavior](https://docs.github.com/en/actions/concepts/security/github_token#when-github_token-triggers-workflow-runs)
