**<sub><sub>![P2 Badge](https://img.shields.io/badge/P2-yellow?style=flat)</sub></sub>  Permit unsupported versions in the hello envelope**

Both protocol fields in the `hello` schema are fixed to v1, so a well-formed client advertising any other ABI fails structural validation before negotiation. That prevents the server from returning the specified typed `unsupported_version` response and makes version skew indistinguishable from a malformed request. Keep non-hello requests fixed to the selected ABI, but allow a bounded protocol identifier in `hello` so dispatch can classify and close unsupported versions as documented.
