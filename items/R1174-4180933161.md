**<sub><sub>![P1 Badge](https://img.shields.io/badge/P1-orange?style=flat)</sub></sub>  Carry the reserved evidence slot into the obligation**

This requires each non-durable evaluation to acquire an evidence slot as a ledger token and then says the obligation owns it, but `CompensableReservation` has no evidence-slot variant and `PostEffectObligation` has no slot field. Consequently there is no ownership path that can transfer the reservation across `enter_effect_boundary`, return it after a committed receipt, or retain it with a buffered post-effect fault; an append or signing failure can therefore reach the boundary without the guaranteed buffer capacity or leak the slot permanently. Add an explicit move-only slot token to the ledger and obligation lifecycle.
