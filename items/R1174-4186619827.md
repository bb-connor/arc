**<sub><sub>![P2 Badge](https://img.shields.io/badge/P2-yellow?style=flat)</sub></sub>  Allow deny lowering without a tool result**

`BoundOutcome.result` is optional and is documented as present for a kernel-observed value output, so a denial naturally carries `None`, but `lower_bound` unconditionally requires a `BoundToolResult` and rule 9 then expects a fabricated empty result. The kernel constructor therefore cannot pass its deny outcome directly to the adapter, despite the rollout requiring replay and provider adapters to use `lower_bound`; make the result optional for denials or have the trusted constructor explicitly supply the bound empty value.
