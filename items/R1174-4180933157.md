**<sub><sub>![P2 Badge](https://img.shields.io/badge/P2-yellow?style=flat)</sub></sub>  Define an ID for unverified initial observations**

The initial observation ID is defined only from a verified launch-record digest, but I7 also requires an initial `unknown` observation when the profile is absent, mismatched, unverifiable, or its lookup fails. Those cases have no verified record digest, so an implementation cannot insert the required stable observation and may leave the new context at the trusted empty-set bottom. Derive the initial ID from a durable context-creation record, including for verification failures, so the fail-closed `unknown` state can always be committed idempotently.
