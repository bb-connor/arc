**<sub><sub>![P2 Badge](https://img.shields.io/badge/P2-yellow?style=flat)</sub></sub>  Reconcile pending intents before an offline bypass**

When a scope already has an unsatisfied journal entry and an offline CLI request tries to narrow it but the journal update fails, this fallback appends the narrower record with `satisfies_intent: None`. The old entry remains unsatisfied because satisfaction requires its exact `StopIntentRef`, yet the head is now already at least as narrow, so boot cannot append the promised narrowing `Restrict`; the stale entry then blocks every later `Resume` or `Relax` indefinitely. Apply or explicitly retire any existing same-scope entry before using the no-intent bypass.
