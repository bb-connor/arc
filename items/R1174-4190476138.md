**<sub><sub>![P1 Badge](https://img.shields.io/badge/P1-orange?style=flat)</sub></sub>  Put successor reservation behind the stop gate**

When an authority remedy begins while a durable stop is active, this new operation can mutate the origin claim before the later `CreateWorkflow` command is checked: `reserve_successor_ordinal` is not one of the seven `RecoveryControl` entry points classified in spec 8, yet its first mutation permanently supersedes the root continuation under O3. The stopped kernel can therefore deny workflow creation while still durably disabling the existing continuation. Classify this reservation as a denied recovery-control entry point, or execute it atomically inside the already stop-gated `CreateWorkflow` path.
