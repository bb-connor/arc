**<sub><sub>![P2 Badge](https://img.shields.io/badge/P2-yellow?style=flat)</sub></sub>  Preserve the owner on task evidence references**

Task projections define their own evidence item shape without `owner_id`, even though the shared `evidence_ref` used by `operation.get` requires that owner and the design has multiple native owners. Once a task contains evidence, clients cannot unambiguously identify which native owner must resolve or verify `native_id`, and this looser duplicate also accepts identifiers rejected by the shared native-ID contract. Reuse `$defs/evidence_ref` for task evidence so task and operation projections retain the same owner-bound reference.
