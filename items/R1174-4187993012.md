**<sub><sub>![P1 Badge](https://img.shields.io/badge/P1-orange?style=flat)</sub></sub>  Represent latch-only denials without a stop epoch**

When `KernelStopped` is caused by S20's host latch or by a `process_only`/`latch_only` stop whose database record has not committed, no `StopEpochId` exists, yet this mandatory receipt shape requires `observed_epoch`. Substituting the current durable head can name a running or unrelated transition, while omitting the field violates the declared signed evidence format, so these fail-closed paths cannot emit a truthful conforming receipt. Make the source discriminated and allow a latch identifier or intent reference when no durable epoch exists.
