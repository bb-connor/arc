**<sub><sub>![P2 Badge](https://img.shields.io/badge/P2-yellow?style=flat)</sub></sub>  Require the frozen vector manifest**

When `MANIFEST.sha256` is deleted, renamed, or omitted from a supplied corpus, this returns successfully and skips every digest check. I verified that copying the five vector files without the manifest still produces both appendices with exit code 0. That lets the CI regeneration gate accept an unfrozen corpus even though this method and the generated draft claim provenance from the frozen vectors; a missing manifest should be an error rather than disabling verification.
