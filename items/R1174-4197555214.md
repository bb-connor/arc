**<sub><sub>![P2 Badge](https://img.shields.io/badge/P2-yellow?style=flat)</sub></sub>  Declare the live authority-loss terminal reason**

When a standard subscription expires or is revoked after activation, this new path requires persisting and optionally emitting `subscription_authority_lost`, but the protocol/schema impact list only adds `subscription_not_restored`, and `TerminalReason` is otherwise left undefined in this design. An implementation following the declared terminal vocabulary therefore has no specified value to encode in the signed tombstone or `Terminal` event for this live failure path. Add `subscription_authority_lost` to the terminal reason and persistence/wire definitions together with the A30 behavior.
