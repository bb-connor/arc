**<sub><sub>![P1 Badge](https://img.shields.io/badge/P1-orange?style=flat)</sub></sub>  Enforce signer liveness before constructing bound verdicts**

When `trusted_kernel_keys` retains historical keys so valid pre-rotation receipts can replay, this membership-only check accepts a receipt signed by a retired or compromised key and can construct an `Allow` outcome. This contradicts M11b, which requires authenticated validity windows and `historical_verification` and rejects compromised keys even for backdated timestamps; the `&[PublicKey]` API cannot enforce that rule. Pass authenticated signer-history entries here and apply M11b's liveness check before constructing any verdict.
