# Chio Wire Schemas v1: capability/

This subtree contains the machine-readable JSON Schema (draft 2020-12) contract for the capability primitives that make up the core authority model in `spec/PROTOCOL.md` section 3 ("Capabilities, Delegation, Attenuation"). The token and grant schemas land together because they are interdependent: `token.schema.json` describes the canonical issued capability (mirroring `CapabilityToken` in `crates/core/chio-core-types`) and `grant.schema.json` describes a single grant carried inside that token's `scope` (mirroring `ToolGrant`, `ResourceGrant`, and `PromptGrant` in the same crate via `oneOf`). A stored revocation is `chio.revocation-entry.v1`, described by `../root_authority/revocation-entry.schema.json`. The schemas are validated against every case in `tests/bindings/vectors/capability/v1.json` on every PR.

`security-binding.schema.json` describes the decoded predicate of the `bind_security_context` caveat (mirroring `CapabilitySecurityBinding` in `crates/core/chio-core-types`). The caveat carries that object as RFC 8785 canonical JSON text, so the schema validates the decoded value and `tests/bindings/vectors/capability/security-binding-v1.json` records the native verifier verdict for each case, including the canonical-bytes rule the schema cannot state.
